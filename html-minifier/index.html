What minifying changes, and what it does not


Minifying removes two things only: HTML comments and whitespace that browsers ignore. Indentation, blank lines and extra spaces between tags disappear, and the file gets smaller without changing a single tag, attribute or word of text.


Your page looks and works exactly the same after minifying, because browsers never showed that whitespace anyway. The only visible difference is the file itself: one dense block of code instead of a neatly indented document.


What stays untouched


Some whitespace matters, so this tool leaves it alone. Text inside pre tags is shown exactly as written, so its spacing is preserved. The same goes for script and style blocks, where removing a space could change how the code runs or looks.


Comments inside those protected blocks are kept too, because they may be part of the code. Only comments in the plain HTML around them are removed.


How much smaller can HTML get?


It depends on how the file was written. A neatly indented page with comments on every section can shrink by a third or more, because indentation and blank lines take up real space across hundreds of lines. A page that is already compact may only shrink by a few percent.


The savings add up across a whole site: every page loads a little faster, and visitors on slow connections notice the difference most. That is why minifying is a standard step before publishing, even though the page itself looks identical.


Keep the original file as your working copy and minify only when you publish. Editing a minified file by hand is slow and error-prone, because everything sits on a few long lines with no structure to guide the eye.


Questions people ask


Is minifying safe for my page?
Yes. Only comments and extra whitespace are removed, so the page looks and works the same.


What about code inside pre tags?
Text inside pre, script and style blocks is left untouched, because its spacing matters.


How much smaller will my HTML get?
It depends on how much whitespace and how many comments the file has — the tool shows the exact bytes saved.


Can I get my original back?
No. Minifying cannot be undone, so keep a copy of the original file.
