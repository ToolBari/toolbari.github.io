What a vCard is


A vCard is a small standard text file that holds contact details: name, phone, email, address and more. Phones, email apps and address books all know the format, so opening a .vcf file offers to save the contact with one tap instead of typing every field by hand.
This generator builds a version 3.0 vCard, the most widely supported form. Fields you leave empty are left out of the file, so the card holds only what you choose to share.


Sharing the contact


Download the .vcf file and send it by message or email, or let the other person scan the QR code on this page. The QR code holds the same vCard text as the file, so scanning it offers to save the contact without any typing at all.
If the details are long, the QR code may not fit: a QR code holds only so much text. In that case the .vcf file still downloads fine, and shortening the note or address will bring the QR code back.


What phones do with a vCard


When a phone opens a .vcf file, it shows the contact details and offers to save them to the address book, filling in every field at once. The same happens when a phone camera scans a vCard QR code, so the other person never has to type anything.
Most phones, tablets and computers understand vCards, which is why the format is still the simplest way to move a contact from one device to another. The file is plain text, so it can also be opened in a text editor to check what it holds.


Questions people ask


What is a .vcf file?
A .vcf file is a standard vCard contact file. Phones and email apps open it and offer to save the contact with one tap.


Which details are required?
Only a first or last name is required. Every other field is optional and is left out of the card when empty.


What does the QR code hold?
The QR code holds the same vCard text as the file, so scanning it offers to save the contact without any typing.


Is my contact data uploaded?
No. The file and the QR code are built in your browser only, and nothing you type is sent anywhere.
