How to trim an audio file

  1. Pick a file. Use the file picker and choose an audio file from your device. The tool shows its length, sample rate and channel count once it has loaded.
  2. Listen first. Press Play to hear the file, and Pause to stop. Pressing Play again after pausing continues where it stopped, so you can find the part you want to keep.
  3. Set the range. Type a start time and an end time in seconds. The end time starts out set to the full length of the file, so you only need to change the times you want to cut.
  4. Trim and download. Press Trim and download WAV. The cut downloads as a new WAV file, and the details of the trim appear below the button, including the length of the cut and the size of the download.

What happens to your file

The tool decodes the file with the Web Audio API, keeps only the samples between the two times you entered, and encodes that range as 16-bit PCM WAV. Every step happens in the page itself: the file is never uploaded, and nothing is sent to a server.

For example, a 60-second audio file with a start time of 10 seconds and an end time of 30 seconds gives a 20-second WAV download. The sound before 10 seconds and after 30 seconds is left out, and the part in between is kept exactly as decoded.

The download is a new file. The original file on your device is never changed, and the output format is always WAV, whatever format the original file was. WAV stores sound without compression, so the download can be larger than a compressed original of the same length.

Questions people ask

What audio files can I trim here?

Any audio file your browser can decode. Pick the file and the tool reads it with the Web Audio API; if the browser cannot read it, you get a plain message instead of a trim.

Is my audio uploaded anywhere?

No. The file is decoded, cut and re-encoded entirely in your browser, and nothing is sent to any server. The original file on your device is never changed.

Why is the download a WAV file?

The tool slices the decoded sound and encodes the selected range as 16-bit PCM WAV in the page. WAV keeps the trimmed sound exactly as decoded, without another round of lossy compression. The download is a new file, not your original file or format.

Can I trim a very long recording?

Yes, but the whole file is decoded into memory first, so a very large file can be slow on a phone and may use a lot of memory. If your device struggles, trim the recording in smaller pieces instead of cutting one long file in a single go.
