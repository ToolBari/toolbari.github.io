Slope Calculator

Enter two points to find the slope of the line through them, its equation in slope-intercept form and its intercepts. The line is plotted on a graph below the result.

The two points must be different: a single point does not define a line. A vertical line has no slope, so the calculator says so instead of inventing a number.

What the slope means

The slope of a line measures how steep it is: how much y changes for each unit that x changes. Between the points (1, 2) and (4, 8) the slope is (8 - 2) / (4 - 1) = 6 / 3 = 2, so the line rises 2 units for every 1 unit it runs to the right. A positive slope rises from left to right, a negative slope falls, a slope of 0 is a flat horizontal line, and a vertical line has no slope at all because the run is zero.

Once the slope m is known, the line can be written as y = mx + b, where b is the y-intercept, the value of y where the line crosses the vertical axis. For the points above, b = 2 - 2 x 1 = 0, so the equation is y = 2x. The x-intercept is where y is 0, which for this line is also 0. The calculator shows each of these steps with your numbers.

Reading the graph

The plot draws the line through your two points, extended in both directions, with the points marked. The axes cross at the origin when it falls inside the plotted range. A steep line has a large slope, a shallow line a small one, and the sign of the slope tells you at a glance whether the line rises or falls.

Questions people ask

How do I find the slope between two points?

Subtract the y values and divide by the difference of the x values: slope = (y2 - y1) / (x2 - x1). For (1, 2) and (4, 8) that is (8 - 2) / (4 - 1) = 2.

What is the slope of a vertical line?

A vertical line has no slope, because both points have the same x value and the formula would divide by zero. Its equation is x = a constant instead of y = mx + b.

What is the y-intercept?

The y-intercept is the value of y where the line crosses the vertical axis, at x = 0. In the equation y = mx + b, the intercept is b.

What does a slope of 0 mean?

A slope of 0 means the line is horizontal: y never changes as x changes. The equation is simply y = a constant.
