Price List Maker

Add your items with prices and categories to build a neat printable price list, grouped by category. The list is made in your browser, so nothing is uploaded.

The prices on the list are exactly the numbers you type. This maker does not suggest prices or check them.

Organising by category

Give each item a category, such as drinks, snacks or stationery, and the list groups the items under category headings. Categories appear in the order you first use them, so the first category you type comes first on the list.

Items without a category are grouped under a plain Items heading, so nothing is left out. Keep category names short and consistent, since two spellings of the same word will make two separate groups.

Updating the list

When a price changes, edit the row and generate the list again. The preview updates straight away, and you can print the new list or download it as a file to keep.

All prices on the list are the numbers you type. This maker never suggests prices, and it does not convert between currencies or add taxes.

Printing tips

Print the list on a single page if it fits, so customers can see everything at once. A clear heading with the shop name at the top makes the list look tidy, and grouping items by category helps customers find what they want quickly.

Put the list where customers can read it before they order, such as on the counter or near the door. When prices change, print a fresh copy and take the old one down, so nobody is quoted an out-of-date price.

Questions people ask

How are categories shown?

Items are grouped under their category headings, and categories appear in the order you first use them on the list.

Can I add more items?

Yes. Use the Add item button for more rows, and Remove on any row to take it out.

What if an item has no category?

Items without a category are grouped under a plain Items heading, so they still appear on the list.

How do I print or keep the list?

Use the Print button to open the print dialog with just the list, or download the list as a file to keep or send.
