Online Screen Ruler

The screen ruler is a draggable, resizable measuring bar that sits on top of this page. It shows pixel, centimetre and inch markings, and you can calibrate it against a real ruler so on-screen sizes match real sizes.

Drag the ruler to move it. Drag the green edge on the right to resize it.

A screen ruler measures CSS pixels, which are not the same as physical pixels on every display. Calibrate against a real ruler before trusting centimetre or inch readings.

How to measure with the screen ruler

Drag the ruler by its body and drop it over whatever you want to measure, then line up the left edge with one end of the object. The tick marks run every 10 pixels, with a longer tick and a number every 50 pixels, so you can read the length at a glance. To resize the ruler, drag the green edge on its right side, or type an exact length in pixels and press Apply.

The readout shows the same length in all three units at once. Use the unit selector to pick which unit is shown first: pixels for web and design work, centimetres or inches for real-world sizes. The steps under the readout show the working, so you can see exactly how the conversion was done.

Calibrating the ruler for real size

Screens differ, so a pixel on your display is not always the same physical size as a pixel on someone else's. The ruler starts at 96 pixels per inch, which is the standard CSS reference value, and that is a good starting point on most desktop screens. For true physical size, hold a real ruler against the screen and adjust the pixels-per-inch value until 10 centimetres on the screen ruler matches 10 centimetres on the real ruler.

Remember that zooming the page changes how big a CSS pixel looks, so calibrate at the zoom level you plan to measure at. If you move the browser to a second monitor, calibrate again for that screen.

Questions people ask

How accurate is the screen ruler?

Pixel readings are exact in CSS pixels. Centimetre and inch readings depend on calibration, so hold a real ruler against the screen and adjust the pixels-per-inch value before trusting them.

How do I calibrate the ruler?

Hold a real ruler against your screen, then change the pixels-per-inch value until the on-screen centimetre marks line up with the real ruler. The default of 96 is the standard CSS reference value.

Why does the ruler change size when I zoom?

Zooming changes how large a CSS pixel appears on your screen, so the ruler grows or shrinks with the page. Calibrate at the zoom level you plan to measure at.

Can I use the ruler on a phone or tablet?

Yes. Drag the ruler with one finger and drag the green edge to resize it. On small screens, type an exact length in pixels instead of dragging for finer control.
