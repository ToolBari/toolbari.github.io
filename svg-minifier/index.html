SVG Minifier

Paste your SVG code and this tool returns a smaller version with the same shapes, colours and structure. It removes comments and unnecessary whitespace, then shows the original size, the minified size and the bytes saved.

Minified SVG keeps the same markup, but a file that relies on whitespace inside text elements may look slightly different. Keep a copy of the original until you have checked the result.

How to minify an SVG file

Paste your SVG code into the box and press Minify SVG. The tool removes XML comments, the whitespace between tags and extra spaces inside tags, then shows the result with the saving in bytes and percent. Copy the minified code or download it as an .svg file.

Everything that affects the picture is kept: every element, every attribute, all path data and all text content. Only the parts that do not change how the graphic renders are removed, so the minified file draws exactly the same shapes.

Why smaller SVG files help

SVG files are text, so comments and indentation add real weight. A smaller file loads faster and uses less data, which matters most for icons and logos that appear on every page of a site. Minifying is a quick win because it changes nothing visible.

Minified code is harder to read and edit, so treat it as the published copy and keep the original as the working copy. If you need to change the graphic later, edit the original and minify it again.

What the minifier removes — and what it keeps

Removed: XML comments, the whitespace between tags, and extra spaces inside tags. These parts take up bytes without changing the picture, so taking them out is safe for almost every SVG file.

Kept: every element and attribute, all path data, all text, and the structure of the document. Nothing is renamed or reordered, and no shapes are simplified, so the minified file is the same graphic in fewer bytes.

Questions people ask

Does minifying change how my SVG looks?

No. The tool only removes comments and whitespace that do not affect rendering, so the graphic looks the same. Text inside the graphic is kept exactly as written.

Can I minify SVG code copied from a design tool?

Yes. Paste the code exactly as exported, including the opening svg tag. If the code does not contain an svg tag, the tool will say so instead of guessing.

How much smaller will my SVG get?

Files exported with comments and indentation usually shrink the most, while already tidy files may shrink by only a few bytes. The tool shows the exact saving for your file.

Is my SVG uploaded anywhere?

No. Everything runs in your browser, so the code you paste never leaves your device.
