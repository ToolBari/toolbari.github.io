How to set an alarm

Choose the time, add a label if you want one, and pick a sound. The label is shown when the alarm rings, so a note like Morning run or Take the cake out of the oven tells you at a glance why the alarm is going off. Press Set alarm and the status line confirms the time, the label and the sound. The current time is shown at the top of the tool and updates every second.

If the time you choose has already passed today, the alarm is set for the same time tomorrow, and the status line says so. That avoids the alarm ringing the moment you set it. You can change the alarm any time by choosing a new time and pressing Set alarm again.

When the alarm rings

At the set time the alarm panel appears with your label, and the chosen sound repeats until you respond. Press Snooze to quiet it for 5 minutes, or Stop to turn it off completely. Snoozing sets a new alarm 5 minutes ahead, so you can snooze again if you need to. The alarm keeps working as long as the page stays open and the device stays awake.

Because the alarm runs in the browser, it depends on the tab staying open. Closing the tab, closing the browser, or letting the device sleep deeply can stop it, so this page suits short reminders and wake-ups where the device is already on. Check the volume before you rely on it, and test the sound once by setting an alarm a minute ahead.

Questions people ask

Does the alarm work if I close the tab?

No. The page must stay open for the alarm to ring, so keep the tab open and your device awake.

What happens if I set a time that has already passed today?

The alarm is set for that time tomorrow.

How long does snooze last?

Snooze delays the alarm by 5 minutes.

Which sounds can I choose?

A gentle beep, a chime, or a bell. The sound repeats until you snooze or stop the alarm.
