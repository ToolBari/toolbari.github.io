What makes alt text useful

Good alt text says what is in the image, not that it is an image. Screen readers already announce the image, so starting with image of wastes the reader's time. Describe the content and, when it matters, the context: what the subject is doing, and where.

If the image contains text, include that text in the alt text, because a screen reader cannot read the image itself. If the image is purely decorative and adds no information, leave the alt text empty rather than describing the decoration.

Which option should I use?

Use the short option when the image is simple and the surrounding text already explains it. A short, clear sentence is enough, and a longer one would only repeat what the reader already knows.

Use the descriptive option for most images, especially when the detail carries meaning, such as a chart, a diagram, or a photo where the mood matters. Use the detailed option when the image is the main content of the page and the reader needs the full picture.

Honest limits

This tool builds sentences from the choices you make. It cannot see your image, so it cannot check whether the subject, action, or setting you picked is right. Always compare the output with the actual image before you publish it.

Alt text is not a caption. Keep it factual and brief, and put any story or opinion in the caption or the surrounding text instead.

Questions people ask

How long should alt text be?

As long as it needs to be to describe the image, and no longer. A short sentence suits a simple image; a detailed image may need two. If the description grows past a few sentences, a caption is usually the better place for it.

Should alt text start with image of?

No. Screen readers already tell the reader it is an image, so those words add nothing. Start with the content instead, for example: a dog running in a park.

What about decorative images?

Leave the alt text empty for images that add no information, such as a border or a background pattern. An empty alt attribute tells screen readers to skip the image.

Does this tool look at my image?

No. It cannot see images at all. It builds sentences from the subject, action, setting, and detail you pick, so check the result against the photo yourself.
