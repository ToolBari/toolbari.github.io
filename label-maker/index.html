How to make labels

Type the text for each label in the box. One label per group, with a blank line between labels. Each label can have up to 4 lines of text; lines after the fourth in a group are left out, and the tool says so.

Pick a sheet preset or set a custom layout. The preview shows the labels laid out on each sheet, and the tool tells you how many sheets the labels need. For example, 25 labels on the L7160 preset need 2 sheets: 21 labels on sheet 1 and 4 on sheet 2.

When the preview looks right, use the Print button. Print at 100 percent, or actual size, with no scaling, so the labels line up with the sheet. This tool makes label sheets, which is different from business cards.

Sheet sizes: Avery L7160 and Avery 5160

Avery L7160 is an A4 sheet with 21 labels, 3 across and 7 down. Each label measures 63.5 by 38.1 millimetres. The top margin is 15.15 millimetres and the left margin is 7.25 millimetres.

Avery 5160 is a US Letter sheet with 30 labels, 3 across and 10 down. Each label measures 2.625 by 1 inch. The preset centres the label grid on the page.

The custom layout lets you set your own rows, columns, label width and height, and page size. The grid is centred on the page. If the labels do not fit on the page, the tool says so instead of drawing a broken layout.

Questions people ask

How many lines can each label have?

Each label can have up to 4 lines of text. Type one label per group and leave a blank line between labels. Lines after the fourth in a group are left out.

Which label sheets does this work with?

Two presets are built in: Avery L7160, an A4 sheet with 21 labels of 63.5 by 38.1 millimetres, and Avery 5160, a US Letter sheet with 30 labels of 2.625 by 1 inch. The custom layout lets you set your own rows, columns, label size and page size.

Why should I print a test sheet first?

Printer scaling shifts alignment, so print one test sheet on plain paper and hold it against a label sheet before printing the real labels. Print at 100 percent, or actual size, with no scaling.

How many sheets will my labels need?

The tool shows the sheet count as you type. For example, 25 labels on the L7160 preset need 2 sheets: 21 labels on sheet 1 and 4 on sheet 2.
