Paste HTML in the box and get Markdown text back, ready to copy or download. The converter runs entirely in your browser, so your markup never leaves the page.








The converter handles common markup. Unusual or broken HTML may convert imperfectly, so check the result before you use it.


What gets converted


Headings become hash headings, paragraphs become plain text separated by blank lines, and bold and italic text keep their emphasis with asterisks. Links keep both their text and their address, images keep their alt text and source, and lists keep their bullets or numbers, including nested lists.
Code blocks become fenced blocks and inline code keeps its backticks, blockquotes keep their quote marker, and horizontal rules become a line of dashes. The result is plain Markdown you can paste into any editor that supports it.


What stays out


Markdown has no place for layout, so wrappers, navigation, sidebars, classes and inline styles are dropped. Only the readable text and its structure survive, in reading order. Script and style content is dropped too, since it is not part of the text.
Tables, forms and embedded media are not converted to Markdown here. If your HTML is mostly a table, convert the table separately and paste the result into the Markdown by hand.


What Markdown looks like


Markdown is plain text with a few simple marks. A heading is a line that starts with one or more hash signs, bold text is wrapped in two asterisks, italic text in one, and a link is written as square brackets with the link text followed by round brackets holding the address.
Because Markdown is plain text, it works anywhere text works: in notes, messages, readme files and documentation. Many sites and apps render it into formatted text, so a document written in Markdown stays readable even before it is rendered.


Questions people ask


Which HTML tags become Markdown?
Headings, paragraphs, bold and italic text, links, images, ordered and unordered lists, code blocks, blockquotes and horizontal rules all convert to their Markdown form.


What happens to scripts and styles?
Script and style content is dropped, since Markdown has no place for it. Only the readable text and its structure are kept.


Can I convert a whole web page?
You can paste any HTML snippet or a full page. Layout wrappers and navigation are stripped, so the result is the page text in reading order.


Does the converter keep links?
Yes. Links become Markdown links with the link text and the address, and images become Markdown images with their alt text.
