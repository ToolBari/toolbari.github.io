How the conversion works


The first row of your CSV becomes the table header, and a row of dashes is added underneath it to separate the header from the body. That separator row also sets the alignment: dashes on the left align left, a colon on the right aligns right, and colons on both sides centre the column.


Every cell is wrapped in pipes, and any pipe character inside your data is escaped so it shows as text instead of splitting the cell. Short rows are padded with empty cells so every row has the same number of columns as the header.


CSV quirks this tool handles


Real CSV files are messier than plain comma lists. A cell wrapped in quotes may contain a comma of its own, or even a line break, and this converter keeps those cells whole instead of splitting them. Two quotes in a row inside a quoted cell become a single quote, which is the standard CSV rule.


Files saved on different systems end their lines differently, so both plain line breaks and carriage-return pairs are accepted. If a row has fewer cells than the header, the missing cells simply come out empty.


Pasting the table into your document


Once converted, the table is plain text you can paste anywhere Markdown is supported: notes apps, documents, wikis and web pages. Paste it on its own lines with a blank line above and below, so the renderer recognises it as a table.


If the table looks wrong after pasting, check that the pipes and dashes survived the paste — some editors reformat pasted text. The download button saves the exact table as a file, which avoids paste surprises.


Questions people ask


Does it handle commas inside cells?
Yes. Cells wrapped in quotes can contain commas, and the quotes are removed in the table.


What about quotes inside a cell?
Doubled quotes in the CSV become a single quote in the table, which is the standard CSV rule.


Can I upload a file instead of pasting?
Yes. Use the file picker to load a CSV file from your device.


Which alignment should I pick?
Left for text, right for numbers, centre for short labels — it only changes how the table looks, not the data.
