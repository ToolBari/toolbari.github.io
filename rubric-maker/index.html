Scores are only as fair as the descriptors you write. Keep each level's wording clear and distinct, and agree the rubric with anyone else who will mark the same work, so the same work gets the same score whoever marks it.

How to build a good rubric

Start with the criteria: the few things that matter most for this piece of work. Three to six criteria are usually enough. Each one should describe a single quality, such as accuracy, presentation or teamwork, so a marker can judge it without guessing what it covers.

Then write a descriptor for every cell: one or two sentences saying what work at that level looks like. The best descriptors describe the work, not the person, and make the step between levels easy to see. Vague words like good or poor on their own do not help a marker decide.

How the scoring works

Each level carries the points you set for it, and the top level is worth the most. When you mark a piece of work, pick the level each criterion reached and the calculator adds the points together. The maximum possible total is the top level's points times the number of criteria.

Criteria with no level chosen count as zero, so pick a level for every criterion before you trust the total. If one criterion matters more than the others, give its levels higher points when you set the rubric up.

Questions people ask

How many criteria can a rubric have?

As many as you add. Short rubrics with three to six criteria are usually easier to mark with than long ones, because each criterion stays clear.

Can I change the level names and points?

Yes. Rename any level and set its points, then press Apply levels to rebuild the table and the score calculator with your new levels.

Do my descriptors save if I leave the page?

No. The rubric lives only in this page, so print it before you leave if you want to keep it.

How is the total score worked out?

Each criterion contributes the points of the level you pick for it. The total is the sum across criteria, shown next to the maximum possible total.
