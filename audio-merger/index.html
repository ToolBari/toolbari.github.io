How to merge audio files

  1. Add files. Pick two or more audio files at once, or add more files later. Each file shows its name and length once it has loaded, and each new file goes to the end of the list.
  2. Arrange the order. Use the Move up and Move down buttons beside each file to change its place, or Remove to take a file out of the list. The merged file follows the list order from top to bottom.
  3. Merge and download. Press Merge and download WAV. The joined file downloads as merged.wav, and the details appear below the button, including the length of each part and the total length.

How the joining works

Each file is decoded with the Web Audio API. The merged file uses the first file's sample rate and channel count; any file with a different sample rate or channel count is converted to match the first file before joining, so every part plays at the right speed.

The decoded samples are then joined end to end in list order — one file after the other, not mixed together — and encoded as 16-bit PCM WAV in the page. For example, two files of 10 seconds and 15 seconds give one 25-second WAV download.

The original files are never changed, and nothing is uploaded: decoding, joining and encoding all happen in your browser. The download is a new WAV file, whatever formats the original files were.

Questions people ask

How many files can I join?

Two or more. Add files in one go or pick more files later; each new file goes to the end of the list. There is no fixed limit, but every file is decoded into memory, so joining many very large files can be slow, especially on a phone.

What sample rate does the merged file use?

The merged file uses the first file's sample rate and channel count. A file with a different sample rate or channel count is converted to match the first file before joining, so every part plays at the right speed.

Is my audio uploaded anywhere?

No. The files are decoded, joined and re-encoded entirely in your browser, and nothing is sent to any server. The original files on your device are never changed.

Can I change the order of the files?

Yes. Use the Move up and Move down buttons beside each file to move it, or Remove to take it out of the list. The merged file follows the list order from top to bottom.
