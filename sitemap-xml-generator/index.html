How to use the generator


Paste your page URLs into the box, one per line. Every URL must be complete, starting with http:// or https:// — a relative address such as /about/ will not work. Then add an optional lastmod date, pick a changefreq, and set a priority between 0.0 and 1.0 if you want one. Press Generate sitemap, then copy the result or download it as sitemap.xml.


If a line is blank or is not a full URL, the generator stops and names the bad line, so you can fix it and try again. The characters & < and > in a URL are escaped automatically, as the protocol requires.


The sitemap protocol, in brief


A sitemap is an XML file whose root element is urlset, with the namespace http://www.sitemaps.org/schemas/sitemap/0.9. Each page is one url entry, and the loc element inside it is required and must hold the page's absolute URL. The optional elements are lastmod, in YYYY-MM-DD form, changefreq, which must be one of always, hourly, daily, weekly, monthly, yearly or never, and priority, a decimal from 0.0 to 1.0 where 0.5 is the default.


One sitemap file holds at most 50,000 URLs and must be no larger than 50 MB. Google ignores changefreq and priority values, and it uses lastmod only when it is consistently accurate — so only add a lastmod date when it is the real date the page last changed.


Worked example


Two URLs, no lastmod, changefreq weekly and priority 0.5 give this sitemap:


<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
<url><loc>https://example.com/</loc><changefreq>weekly</changefreq><priority>0.5</priority></url>
<url><loc>https://example.com/about/</loc><changefreq>weekly</changefreq><priority>0.5</priority></url>
</urlset>


Questions people ask


What is an XML sitemap?
An XML sitemap is a file that lists the pages of a website in a format search engines can read. It helps them find and crawl pages they might otherwise miss, especially on large sites or sites with pages that few other pages link to.


Which fields does a sitemap entry need?
Only the loc field is required, and it must be the full absolute URL of the page. The lastmod, changefreq and priority fields are optional, and this generator adds each one only when you fill it in.


Does Google use changefreq and priority?
No. Google ignores changefreq and priority values. It uses lastmod only when it is consistently accurate, so only add a lastmod date when it is the real date the page last changed.


How large can a sitemap be?
One sitemap file can hold at most 50,000 URLs and must be no larger than 50 MB. Larger sites split their URLs across more than one sitemap file.
