Math Worksheet Generator

Create a printable maths worksheet with the operation, number range and question count you choose. Every worksheet comes with an answer key, so marking takes minutes.

Questions are generated at random, so no two worksheets are the same. The answer key is generated from the same questions.

How to make a worksheet

Choose an operation first: addition, subtraction, multiplication, division, or a mix of all four. Then set the number range the questions should use, and how many questions you want, from 5 to 50. Press Generate worksheet and the questions appear as a numbered list, ready to answer. The answer key is made at the same time but stays hidden until you press Show answer key, so you can print the questions on their own.

Division questions are built backwards so they always work out to a whole number: the tool picks the divisor and the answer first, then works out the number to divide. Subtraction questions are arranged so the answer is never negative. That keeps every worksheet fair for the age it is aimed at, with no awkward surprises in the middle of a page.

Making it the right level

For younger children, keep the range small, such as 1 to 10, and use one operation at a time. As confidence grows, widen the range and move to mixed operations, which ask the child to read each question properly instead of repeating the same move. A short worksheet of 10 questions is enough for a quick practice session, while 30 or more suits a longer homework sheet.

Because each worksheet is random, you can generate a fresh one every day without repeating the same sums. If a child finds a page too easy or too hard, change the range and generate again: the tool takes seconds, and the answer key updates with the new questions. Print with the key hidden for the child, and show it only when it is time to mark.

Questions people ask

Which operations can I choose?

Addition, subtraction, multiplication, division, or a mix of all four. Division questions always work out to a whole number.

How many questions can I make?

From 5 to 50 questions per worksheet.

Where is the answer key?

The answer key appears below the questions. Use the Show answer key button to show or hide it before printing.

Can I print the worksheet?

Yes. Press Print to open your browser print dialog and print the worksheet, with or without the answer key showing.
