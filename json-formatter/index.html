Common reasons JSON fails

  • A comma is missing between two items, or one is left trailing at the end.
  • Keys or text use single quotes — JSON requires double quotes.
  • A bracket or brace is opened and never closed.
  • Comments are included — standard JSON does not allow them.

Questions people ask

How do I fix broken JSON?

Paste the JSON into the validator. If it is invalid, the error message is shown; the usual causes are a missing comma, a trailing comma, single quotes instead of double quotes, or an unclosed bracket. Fix the reported spot and validate again.

What is the difference between formatting and minifying JSON?

Formatting adds line breaks and indentation so people can read the structure. Minifying removes unnecessary whitespace so the same data takes fewer bytes. Neither changes the data itself.

Is my JSON uploaded to a server?

No. This formatter runs with JavaScript in your browser; the text you paste is not sent anywhere by this page.
