IBAN Validator

Check whether an IBAN is correctly formed in seconds. This tool runs the official mod-97 check, confirms the country code and length, and shows the IBAN in neat groups of four.

This check only confirms the format and check digits of an IBAN. It cannot tell you whether the account exists, is open, or belongs to a particular person, and it performs no bank lookup.

How the check works

Every IBAN is checked the same way, in three steps. First, the country code is read from the first two letters, and the total length is compared with the fixed length for that country. Second, the first four characters are moved to the end of the IBAN. Third, every letter is converted to a number (A is 10, B is 11, and so on up to Z is 35), and the resulting long number is divided by 97. A correctly formed IBAN always leaves a remainder of 1.

If any step fails, the IBAN as typed cannot be a working account number, and the most common cause is a single mistyped, missing, or extra character. Copying the IBAN from the original document instead of retyping it avoids most mistakes.

What a valid result means

A valid result means the IBAN is well formed: the country code is real, the length is right, and the check digits are consistent with the rest of the number. It does not mean the account exists, that it is open, or that it belongs to the person you expect. Only the bank holding the account can confirm that.

Always confirm account details with the recipient through a channel you trust before sending money, and never share your full IBAN in public places such as social media posts or open chat groups.

Questions people ask

What is an IBAN?

An IBAN, or International Bank Account Number, is a standard way of writing a bank account number so it can be used across borders. It starts with a two-letter country code, then two check digits, then the bank and account identifiers for that country, and it can be up to 34 characters long.

What does the mod-97 check do?

The mod-97 check rearranges the IBAN, converts its letters to numbers, and divides the result by 97. A correctly formed IBAN always leaves a remainder of 1, so any other remainder means the IBAN contains a mistake.

Why does my IBAN fail the length check?

Every country that uses IBANs has one fixed length, so an IBAN that is too short or too long for its country code cannot be right. The usual cause is a missing or extra character when the number was copied or typed.

Does a valid IBAN mean the account exists?

No. The check only confirms the format and the check digits. It performs no bank lookup and cannot confirm that an account exists, is open, or belongs to a particular person.
