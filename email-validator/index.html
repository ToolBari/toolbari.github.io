Email Validator

Paste one email address or a list, one per line, and get a verdict for each one: valid syntax, or the exact problem, such as a missing @ or a missing dot in the domain. Common domain typos are flagged too, with a suggestion for the domain you probably meant.

How to use the Email Validator

Paste one email address, or a list with one address on each line, into the box above, then press Validate. Every address gets its own verdict below the buttons: either valid syntax, or the specific problem that was found, so you can fix it and check again.

Press Load examples to try the three worked examples below and see what each verdict looks like. Press Clear to empty the box and the results and start over. Nothing you paste is sent anywhere: every check runs in your browser, and the page stores nothing.

A valid result means the address is written in the right shape. It does not mean the mailbox exists, so always double-check an address with its owner before you rely on it for something important.

What the validator checks

Each address is checked against the shape of a normal email address: a local part, one @ sign, and a domain with at least one dot. When an address fails, the verdict names the exact problem so you know what to fix:

  • missing @ — the address has no @ sign at all
  • more than one @ — the address has two or more @ signs
  • spaces — the address contains a space
  • consecutive dots — two dots in a row, in the local part or the domain
  • missing domain — nothing after the @ sign
  • missing dot in the domain — the domain has no dot, so there is no top-level domain
  • top-level domain shorter than 2 characters — the part after the last dot is only one character
  • empty local part — nothing before the @ sign

When the syntax is valid, the validator also checks the domain against four very common domains — gmail.com, yahoo.com, outlook.com and hotmail.com. If the typed domain is one or two edits away from one of them, the validator suggests the likely domain, because that is usually a typing mistake rather than a real domain.

Worked examples

  • name@gmail.com — valid syntax.
  • name@gamil.com — valid syntax, with the suggestion "Did you mean name@gmail.com?"
  • name@domain — invalid, missing dot in the domain.

Questions people ask

Does a valid result mean the address exists?

No. This tool checks syntax only and never contacts a mail server, so a valid result means the address is written correctly, not that the mailbox exists or accepts mail. Only the owner of the domain can confirm that an address is real.

Why does the validator flag gamil.com?

Because gamil.com is close to gmail.com, a very common domain, so it is usually a typing mistake. The validator suggests the likely domain when the typed domain is one or two edits away from gmail.com, yahoo.com, outlook.com or hotmail.com.

Can I check more than one address at a time?

Yes. Paste a list with one address per line and press Validate. Each address gets its own verdict, with the specific problem named for any address that fails.

Is any address sent anywhere?

No. Every check runs in your browser on your own device and nothing is uploaded or stored. The addresses you paste never leave the page.
