Phone Number Formatter

Type a phone number and pick its country to see it in international format, with the country code and the digits grouped the way people read them. The tool only reformats what you type; it never checks whether a number exists.

This tool only changes how a number looks. It does not check whether a number exists, is in service, or belongs to anyone.

How the formatting works

The tool first keeps only the digits, dropping spaces, dashes, brackets and the plus sign. It then removes an international prefix (00) and the country code if the number already has one, and drops the trunk 0 used for calls inside a country. What is left are the national digits, which are grouped using the pattern for the chosen country and shown after the country code.

Each country has its own dial code and grouping pattern. A Bangladesh mobile number keeps 10 national digits grouped 5 and 5, a United States number keeps 10 digits grouped 3, 3 and 4, and an Australian mobile number keeps 9 national digits grouped 3, 3 and 3. The steps under the result show exactly what was removed and how the digits were grouped.

Worked example

Take 01712345678 with Bangladesh selected. The trunk 0 is removed, leaving 1712345678, ten national digits. They are grouped 5 and 5 as 17123 45678, and the country code is added in front: +880 17123 45678. A United States number such as 2025550143 has no trunk 0 to remove, so the ten digits are grouped 3, 3 and 4 as 202 555 0143 and shown as +1 202 555 0143.

If you paste a number that already starts with +880 or 00880, the tool strips that prefix first and formats the same national digits, so the result is the same. Numbers with brackets or dashes, such as (202) 555-0143, are cleaned to digits before formatting.

Questions people ask

Does this tool check if a number is real?

No. It only reformats the digits you type. It never looks a number up and cannot tell you whether a number is in service.

Why was the leading 0 removed?

The 0 is the trunk prefix used for calls inside a country. International format drops it and uses the country code instead.

What if my number already starts with + or 00?

The tool strips the + or 00 prefix and the country code, then formats the national digits again, so the result is the same.

Which countries are supported?

Bangladesh, the United States and Canada, the United Kingdom, India, Australia and Germany. Each one has its own dial code and grouping pattern.
