List Shuffler

Paste a list with one item per line and press Shuffle to mix it into a random order. The shuffled list appears numbered, ready to copy or download as a text file.

The shuffle uses your browser's built-in random number generator. It is fine for games, draws and classroom picking, but it is not suitable for anything that needs certified randomness.

How to shuffle a list

Paste your list into the box with one item on each line, then press Shuffle. Blank lines are ignored, so extra spacing does not matter, and each item appears exactly once in the shuffled result. Long lists work just as well as short ones.

Press Shuffle again any time to mix the same items into a new order. The list you pasted stays in the box until you clear it, so you can shuffle the same group as many times as you like.

Ideas for using a shuffled list

A shuffled list is the fair way to draw names out of a hat, pick a random order for presentations, or split a group into teams. Shuffle the names, then take them in order from the top of the list. For two teams, deal the shuffled names alternately down the list so each side gets a fair mix.

It also works for revision: shuffle a list of topics and work through them in the new order, so you cannot guess what is coming next. Copy the result to keep it, or download it as a text file. Teachers use the same trick to pick who answers first, because a shuffled list removes any hint of favouritism.

Questions people ask

How should I format my list?

Put one item on each line. Blank lines are ignored, so extra spacing between items does not affect the shuffle.

Can the same item appear twice in the result?

No. Shuffling only changes the order of the items you pasted. Every item appears exactly once, unless you pasted it twice yourself.

Is the shuffle really random?

The order comes from your browser's built-in random number generator, using a Fisher-Yates shuffle that gives every ordering an equal chance.

What is a Fisher-Yates shuffle?

It is a method that walks through the list from the end and swaps each item with a randomly chosen item before it. Every possible order is equally likely.
