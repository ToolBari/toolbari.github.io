What this checker looks for

Paste a whole page of HTML and the checker reports six common problems, with counts and the exact lines affected:

  • Images without an alt attribute, or with an empty alt — a screen reader has nothing to announce for the image.
  • Form inputs without an associated label — the label must be linked with the for attribute or wrapped around the input. Buttons and hidden inputs are not checked, because they do not need labels.
  • Skipped heading levels, for example an H1 followed directly by an H3 — headings should step down one level at a time.
  • Vague link text — "click here", "read more" and "link" say nothing about where the link goes.
  • A missing lang attribute on the html element — screen readers need it to pick the right pronunciation.
  • A missing or empty title element — the title names the page in browser tabs and search results.

This checks a whole pasted page, which is broader than checking one colour pair.

How colour contrast is judged

The contrast checker takes a foreground and a background colour and computes the ratio from the WCAG formula: the lighter luminance plus 0.05, divided by the darker luminance plus 0.05. Relative luminance measures how light a colour looks to the human eye. WCAG 2.1 sets these thresholds: AA needs 4.5 to 1 for normal text and 3 to 1 for large text; AAA needs 7 to 1 for normal text and 4.5 to 1 for large text; user interface components need 3 to 1. Large text means 18 point (24 pixels) or larger, or 14 point (18.66 pixels) bold or larger.

What automated checks cannot catch

These checks look at code, not meaning. They cannot tell whether an alt text actually describes its image, whether a page works with a keyboard alone, or whether the reading order makes sense with a screen reader. A page can pass every check here and still have accessibility problems, so manual review is still needed.

Questions people ask

What does the accessibility checker look for?

It checks pasted HTML for six common problems: images missing an alt attribute or with an empty alt, form inputs without an associated label, skipped heading levels, vague link text, a missing lang attribute on the html element, and a missing or empty title element.

What contrast ratio does text need?

WCAG 2.1 Level AA asks for at least 4.5 to 1 for normal text and 3 to 1 for large text. Level AAA asks for 7 to 1 for normal text and 4.5 to 1 for large text, and user interface components need 3 to 1.

Does passing these checks mean my page is accessible?

No. Automated checks catch only some issues, and a page can pass all of them and still have accessibility problems. Manual review, including keyboard testing and testing with a screen reader, is still needed.

What counts as large text?

Large text is 18 point, or 24 pixels, and larger, or 14 point, or 18.66 pixels, and larger when the text is bold. Everything smaller counts as normal text for contrast purposes.
