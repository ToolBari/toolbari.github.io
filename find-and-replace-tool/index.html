Find and Replace Tool

Paste your text, type what to find and what to put in its place, and every match is replaced at once. You can match case exactly or use a regular expression, and the tool reports how many replacements it made.

Replacements cannot be undone on this page, so check the result before copying it away. With regular expressions switched on, characters such as dots and brackets have special meanings, so test a tricky pattern on a small piece of text first.

How the options work

With match case switched off, the search ignores capital letters, so finding cat also replaces Cat and CAT. With it switched on, only text with exactly the same capital letters is replaced. The replacement text is used exactly as typed, except in regular expression mode, where a dollar sign followed by an ampersand inserts the matched text.

Regular expressions let you match patterns instead of fixed words. For example, a pattern of digits matches every number in the text at once. Characters such as dots, brackets and stars then have special meanings, so switch the option off for plain word searches. If a pattern is not valid, the tool says so instead of changing anything.

Tips for clean replacements

Leave the replacement box empty to delete every match. The count above the result tells you how many replacements were made, or that no matches were found. Your original text stays in the input box, so you can adjust the terms and run it again as many times as you like.

Copy the result to the clipboard or download it as a plain text file when you are happy with it. Nothing is saved or uploaded anywhere; everything happens in your browser. For a long document, replacing a repeated word or a mistyped name takes a single click, and the count confirms the change.

Questions people ask

How do I delete text instead of replacing it?

Leave the replacement box empty. Every match of the find term is then removed, and the count still tells you how many matches were deleted.

What does match case do?

With match case switched on, only text with exactly the same capital letters is replaced. With it off, the search ignores capital letters, so finding 'cat' also replaces 'Cat' and 'CAT'.

What can I do with regular expressions?

Regular expressions let you match patterns instead of fixed words, such as all numbers or all words starting with a letter. Characters such as dots and brackets then have special meanings, so switch the option off for plain word searches.

Does the tool change my original text?

No. The original stays in the input box and the result appears separately, so you can adjust the terms and run it again. Nothing is saved or uploaded anywhere.
