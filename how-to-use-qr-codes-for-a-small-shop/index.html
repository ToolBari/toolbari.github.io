How to Use QR Codes for a Small Shop

A QR code is a square pattern that a phone camera reads and turns into a web page, a Wi-Fi login or a short form. For a small shop it is a cheap way to share information without printing new signs every time something changes. This guide covers the practical uses, where to place a code, how big to print it and how to test it before it goes on display.

Practical uses for a QR code in a small shop

A QR code is only worth printing if it saves the customer time or saves you work. Start with one or two uses, get them working well, and only then add more.

Menu and price lists. A code on the counter or on each table can open your menu or price list on the customer's own phone. This works well for cafes, food stalls and salons, where the list changes often and reprinting it every time costs money. When a price changes, you update the page once and every code in the shop shows the new price. Keep the page short and easy to read on a small screen.

Wi-Fi sharing. If you offer Wi-Fi to customers, a QR code can connect a phone to the network without anyone typing a long password. Put the code near the seating area or the counter, and label it plainly so people know what it does. Remember to change the code if you ever change the Wi-Fi password.

Payment links. A QR code can open a payment page so a customer can pay without cash and without reading out a number. This is useful at a market stall or a counter where the queue moves fast. Keep the setup simple: one code, one payment destination, and a clear label telling the customer what happens when they scan it. Do not print a payment code until you have tested a real payment through it yourself.

Feedback forms. A code that opens a short feedback form gives customers a quiet way to tell you what went well and what did not. Keep the form short — three or four questions at most — and place the code where customers see it after they have used your service, near the exit or on the receipt. Check the answers regularly: a form nobody reads teaches customers that their words go nowhere.

Opening hours and location. A code on your window or door can open a page with your opening hours and your address. This helps people who walk past when you are closed: instead of guessing when you open, they scan and find out.

Placement: where a code actually gets scanned

A QR code only works if people notice it and can hold their phone steady in front of it. The best spots are the places where a customer naturally stops and waits: the counter, the till, a table, or the wall beside the entrance. A code at eye level or lying flat on a counter is easy to scan; a code behind the counter, high on a wall, or on a door that swings open will mostly be ignored.

Light matters as much as position. A code in a shadow, behind glass that reflects the sun, or under a flickering light is hard for a phone camera to read. If you put a code on a window, check it at different times of day, because glare that is absent in the morning can make it unreadable in the afternoon.

Give each code a clear label. A bare square pattern tells a customer nothing, and most people will not scan a code when they do not know what it does. A short line above or below the code — "Scan for the menu", "Scan for Wi-Fi", "Scan to pay" — should say what happens after the scan, not just "Scan me".

Keep the area around the code clear. A code crowded by posters, price tags and other codes is easy to miss and hard to aim at. If you have more than one code, separate them and label each one, so a customer does not scan the Wi-Fi code when they wanted the menu.

Size: how big a printed code should be

The right size depends on how far away the customer stands when they scan. A code on a counter is scanned from arm's length, so it can be small. A code on a wall or a window is scanned from a step or two away, so it must be larger. As a rule of thumb, the code should be about one tenth of the distance people scan it from: a code scanned from half a metre away should be at least 5 centimetres square, and a code scanned from a metre away should be at least 10 centimetres square.

For a counter or table code, at least 2 centimetres square is a sensible minimum. Below that size, many phone cameras struggle, especially in poor light or on an older phone. A code that holds a long web address is harder to scan than one holding a short address, because it packs more detail into the same square, so print a long-link code larger than the minimum.

Leave a quiet margin around the code. Phone cameras need a plain border around the square to tell where the code starts and ends. Leave a margin of plain white space at least as wide as four of the small squares inside the code, on all four sides. A code printed right up against a coloured border, a picture or another block of text will scan slowly or not at all.

Print quality matters. A code printed at low quality, or photocopied several times, can lose the sharp edges the camera needs. Print at the highest quality your printer offers, on plain white paper or card, and replace the printout when it fades, creases or gets dirty.

Test every code before you print it

Never print a batch of codes without testing them first. A printed code with a mistake is wasted paper, and worse, a customer who scans a broken code will not try again. Testing takes a few minutes and saves a lot of trouble.

Start by scanning the code on your own phone and checking that it opens the right page. Then scan it on a second phone, ideally a different model, because cameras and software vary. Check that the page loads quickly and looks right on a small screen. If the page is slow or hard to read, fix the page before you print the code.

Next, print one test copy at the exact size you plan to use, and scan that copy from the distance and angle your customers will use, in the light the shop actually has. If the code is slow to scan, print it larger or move it to better light. If it will not scan at all, check the print quality and the quiet margin around it.

Test again after the code goes up. A code that scanned fine on your desk may struggle on a glossy window in sunlight, or on a counter under a shelf shadow. Ask a friend or a regular customer to try it without any help from you: if they hesitate, the label or the position needs work. Recheck your codes every time the page they link to changes — a link that moves turns a working code into a dead end.

Questions people ask

Where should I place a QR code in my shop?

Put it where a customer naturally stops and waits: the counter, the till, a table, or the wall beside the entrance. Keep it at eye level or on a flat surface in good light, and make sure nothing blocks it. A code behind the counter or high on a wall rarely gets scanned.

How big should a printed QR code be?

For a code scanned from arm's length, at least 2 centimetres square is a sensible minimum. For a code on a wall or window that people scan from a metre or more away, print it much larger. As a rule of thumb, the code should be about one tenth of the distance people scan it from.

What should a shop QR code link to?

Link to something the customer wants right then: your menu or price list, your Wi-Fi login, a payment page, a feedback form, or your opening hours and location. One code should do one job, and the page it opens should load quickly on a phone.

How do I test a QR code before printing?

Scan it yourself on more than one phone, from the distance and angle your customers will use, and check that it opens the right page. Print a test copy at the real size first, then scan that copy too. If a code is hard to scan in a test, it will be harder for a customer in a hurry.
