CSV Data Cleaner

Tidy messy spreadsheet data in seconds. Paste or upload a CSV file to trim extra spaces, drop empty rows, remove duplicates and fix delimiters, then download the cleaned file.

Cleaning happens in your browser and your original file is never changed. Always check the cleaned file before using it for anything important.

What the cleaner does

Four cleanups run over your data. Trimming removes extra spaces from the start and end of every cell. Empty rows, where every cell is blank, are dropped. Rows that repeat an earlier row exactly are removed, keeping the first copy. And if your file uses semicolons, tabs or pipes instead of commas, the delimiter is detected from the first row and converted to commas.

Cells wrapped in quotes keep their contents intact, including commas inside the quotes, so addresses and sentences survive the cleanup unchanged. The row counts shown after cleaning tell you exactly what changed.

What it does not do

The cleaner does not fix spelling, change values, or guess what a cell should say. Numbers stay as typed, and dates are not reformatted. If a row has a different number of cells than the others, it is kept as it is, because only you know which column a stray value belongs in.

For anything important, open the cleaned file and scan it once before using it. A quick check catches the rare case where a messy file needs a human decision.

Working with big files

Large files paste and clean the same way as small ones, but very large pastes can be slow in some browsers. If a file has tens of thousands of rows, upload it with the file button instead of pasting, and give the page a moment to finish before downloading.

Because everything runs in your browser, there is no upload limit and no waiting for a server. The cleaned file is built on your device and stays there until you download it.

Questions people ask

What is a CSV file?

A CSV file stores spreadsheet data as plain text, with one row per line and cells separated by commas. Almost every spreadsheet app can open and save CSV files.

Which delimiters are fixed?

Semicolons, tabs and pipes are detected from the first row of your data and converted to commas. If the first row already uses commas, nothing is changed.

Are quoted cells handled?

Yes. Cells wrapped in double quotes keep their contents, including commas and line breaks inside the quotes, and doubled quotes inside a quoted cell are read as a single quote.

Is my data uploaded?

No. The cleaning runs entirely in your browser. Your file is never sent anywhere, and the original file is not changed.
