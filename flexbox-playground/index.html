Flexbox Playground

Change flex-direction, justify-content, align-items, flex-wrap and gap, and watch a row of five numbered boxes rearrange instantly in the live preview. The matching CSS for the flex container appears below the preview, ready to copy into your stylesheet.

Your CSS






The preview shows five boxes of equal size in one container, so it shows how the container properties behave rather than how flex items grow or shrink. Item sizing is controlled by flex-grow, flex-shrink and flex-basis on the items themselves, which this playground does not set.


How to use the Flexbox Playground


Pick a flex-direction first: row lays the boxes out left to right, column lays them out top to bottom, and the two reverse options flip the order. The five numbered boxes in the preview rearrange every time you change a setting, so you can watch each property work on its own.


Justify-content controls how the boxes spread along the main axis, and align-items controls how they line up on the cross axis. Try space-between with center to see the classic spread-out row, then switch the direction to column and watch the same settings move the boxes vertically instead.


When the layout looks right, press Copy CSS and paste the rule into your stylesheet. Give your container the class flex-container, or change the class name in the copied CSS to match a class you already use.


What each flexbox property does


    

  • flex-direction sets the main axis: row runs left to right, column runs top to bottom, and the reverse values run the same axes in the opposite direction.
    • 

  • justify-content lines items up along the main axis. flex-start packs them at the start, center centres them, and space-between pushes the first and last items to the edges with the leftover space shared between the items.
    • 

  • align-items lines items up along the cross axis. center centres each item, flex-start lines them up at the top of a row, and stretch makes each item fill the full height of the container.
    • 

  • flex-wrap decides what happens when the items do not fit on one line. nowrap keeps them on a single line, while wrap lets them flow onto extra lines.
    • 

  • gap sets the space between items, in pixels. It applies between every pair of neighbouring items, in both directions when wrapping is on.
    • 



Questions people ask


What is the difference between justify-content and align-items?
Justify-content lines items up along the main axis, which runs left to right when the direction is row. Align-items lines them up along the cross axis, which runs top to bottom when the direction is row.


What does space-between do?
Space-between spreads the boxes out so the first box touches the start edge, the last box touches the end edge, and the space left over is shared equally between the boxes. No extra space is added before the first box or after the last one.


What happens when flex-wrap is set to wrap?
With wrap, boxes that do not fit on one line move onto a second line instead of being squeezed smaller. With nowrap, the default, all boxes stay on a single line even if that means they shrink.


Why does the layout look different in a column?
In a column layout the main axis runs top to bottom, so justify-content moves the boxes vertically and align-items moves them horizontally. The two axes swap when the direction changes, which is why the same settings look different in a row and in a column.
