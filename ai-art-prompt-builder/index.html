How to build a good art prompt

Start with a clear subject: one thing, named plainly, with one or two details that make it yours. Then add a style, a kind of lighting, a camera angle, and a mood. Each picker adds one layer of information, and together they describe the picture well enough for an image tool to work with. If the first result is not what you imagined, change one picker at a time, usually the style or the lighting, and compare the results. The extra details box is for anything the pickers do not cover, such as a season, a colour, or a small object.

What each picker adds

Style sets the look of the picture, from photorealistic to watercolor or pixel art. Lighting sets the time and feeling of the scene: golden hour feels warm, moonlight feels quiet, and neon glow feels modern. Camera angle sets the viewpoint: a close-up fills the frame with the subject, an aerial view shows the whole scene from above, and a low angle makes the subject feel tall. Mood sets the atmosphere in one word, so the picture feels cheerful, calm, mysterious, or playful instead of flat.

Trying variations

The three variation buttons keep your subject, camera angle, mood, and extra details, and change only the style and lighting. Each variation picks a different pair, so you can compare three distinct looks for the same subject without rebuilding the prompt each time. Variations are a fast way to explore: if one style feels right but the lighting is wrong, rebuild with that style and try the lighting options one by one. Copy the prompt you like best and paste it into your image tool.

What this tool does not do

This tool writes prompt text only. It does not generate images, and it is not connected to any image service. That is different from a prompt-to-image generator, which turns a prompt into a picture. Use this builder to write the words, then paste them into an image tool of your choice. If a prompt mentions a real person or a trademarked character, check the image tool's rules before you use it, and only use pictures you have the right to use.

Questions people ask

Does this tool make images?

No. It writes prompt text only and generates no images. Paste the finished prompt into an image tool of your choice to make the picture.

Where do I paste the prompt?

Into any image-generation tool or app that accepts a text prompt. Copy the prompt with the copy button, then paste it where that tool asks for a description.

How do the variations work?

Each variation keeps your subject, camera angle, mood, and extra details, and changes only the style and lighting to a different pair. Variation 1, 2, and 3 each pick a different combination.

Can I add my own details?

Yes. Use the extra details box for anything the pickers do not cover, such as a season, a colour, a background object, or a texture.
