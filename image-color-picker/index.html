How to pick a color

Choose an image file from your device and it appears on the canvas, scaled to fit the page. Click any pixel and the tool reads the red, green and blue values of that exact pixel, then shows the color in three formats at once. The swatch fills with the picked color so you can see it at a glance.

The loupe shows the nine-by-nine pixel area around your click, magnified fifteen times. It helps when you need a color from a small detail, like a single letter or a thin line, because you can see exactly which pixel you hit. Each value has its own copy button, so you can paste the color straight into your design tool or code.

What HEX, RGB and HSL mean

HEX writes a color as six hexadecimal digits after a hash, two digits each for red, green and blue. Pure red is FF0000, pure white is FFFFFF and pure black is 000000. RGB writes the same three channels as numbers from 0 to 255, so pure red is rgb(255, 0, 0).

HSL describes color differently: hue is the position on the color wheel from 0 to 360 degrees, saturation is how vivid the color is, and lightness is how close it is to black or white. HSL is handy when you want a lighter or darker version of a color, because you only change the lightness number.

Questions people ask

What image types can I upload?

Any image your browser can open, including JPG, PNG, GIF and WebP. If a file cannot be opened, the tool says so and asks for a different file.

Is my image uploaded anywhere?

No. The image is read in your browser and never leaves your device. Nothing is sent to a server at any point.

Why does the color differ from another app?

Compressed images store colors approximately, and different apps may apply different color profiles. The picker reads the exact pixel stored in the file you uploaded.

Can I pick a color from a screenshot?

Yes. Take a screenshot, save it as an image file, upload it here and click the pixel you want.
