Image Splitter

Pick an image, choose how many rows and columns to split it into, and download each tile as its own PNG file. The preview shows the grid with dividing lines before you download anything.

Choose an image to see the preview.

Tiles download as PNG files, re-encoded from the original image, so the format and file size change. The preview is scaled to fit your screen; the downloaded tiles are always full size. Very large images may be slow on a phone.

How to split an image into tiles

Choose an image file from your device. The image never leaves your browser: it is drawn on a canvas in the page, split there, and each tile is saved from that canvas.

Set the number of columns and rows. Each runs from 1 to 6, so the smallest split is a single tile and the largest grid is 6 by 6, which is 36 tiles. The preview updates as you change the numbers, and the dividing lines show exactly where each tile ends.

Each tile has its own download button, labelled with its row, its column and its size in pixels. There is no ZIP download: without external libraries there is no ZIP writer, so each tile downloads separately as its own PNG file.

For example, a 900 by 600 image split into 3 columns and 2 rows gives six tiles, each 300 by 300 pixels.

How the tiles are divided

Tiles are exact pixel divisions of the original image. The width is divided by the number of columns and the height by the number of rows, using whole pixels only, so no tile is ever stretched or squeezed.

When the size does not divide evenly, any remainder pixels go to the last row and the last column. A 901 by 601 image split into 3 columns and 2 rows gives tiles 300 pixels wide, except the last column, which is 301 pixels wide, and tiles 300 pixels tall, except the last row, which is 301 pixels tall.

This tool exports a grid of tiles, which is different from cropping one area. If you only need one part of an image, split it and download just the tile you want.

Questions people ask

What image formats can I split?

Any image your browser can open: PNG, JPEG, WebP and GIF files all work. The tiles always download as PNG files, whatever format the original image was in.

How many tiles can I make?

Rows and columns each run from 1 to 6, so the largest grid is 6 by 6, which is 36 tiles. A grid of 1 row and 1 column gives back the whole image as a single tile.

What happens when the image size does not divide evenly?

Tiles are exact pixel divisions of the original, and any remainder pixels go to the last row and the last column. For example, a 901 by 601 image split into 3 columns and 2 rows gives tiles 300 pixels wide, except the last column, which is 301 pixels wide, and tiles 300 pixels tall, except the last row, which is 301 pixels tall.

Can I download all the tiles at once?

No. There is no ZIP download, so each tile downloads separately with its own button. This keeps the tool working with no external libraries and no uploads.
