How a Wi-Fi QR code works


A Wi-Fi QR code holds the network name, the password and the security type in a short text format that phones understand. When a phone camera reads the code, the phone offers to join the network straight away, with no typing and no risk of a mistyped password.
The code is drawn here in your browser by a small QR encoder built into this page. Nothing you type is sent anywhere, and the code works offline once it is printed or saved.


Tips for sharing


Print the code and put it where guests can see it, such as on a fridge or near the front door. If your network is hidden, tick the hidden box so the phone knows to look for a network that does not broadcast its name.
Remember that the password is inside the code itself. Anyone with a photo of the code can join, so keep printed copies where only your guests can see them, and make a new code if you change the password.


When a scan does not work


If the phone reads the code but does not join, check the network name and password for typing mistakes, and check the security type matches the router. A single wrong character is enough to stop the connection, even though the code itself scans fine.
If the camera does not recognise the code at all, try moving the phone closer or further away, or print the code larger. A code printed too small, or photographed at a sharp angle, can be hard for a camera to read.


Questions people ask


Which phones can scan a Wi-Fi QR code?
Most modern phones join a network straight from the camera app when they see a Wi-Fi QR code. If the camera does not offer it, use the Wi-Fi settings on the phone.


Does the code store my password?
Yes. The password is written into the code itself, which is how the phone can join without typing. Keep the printed code where only guests can see it.


What security type should I pick?
Pick the type your router uses. Most home networks use WPA or WPA2, older ones may use WEP, and open networks need no password.


Is my password sent anywhere?
No. The QR code is drawn in your browser only, and nothing you type is sent to any server.
