Function Graph Plotter

Type a function of x, such as x^2 - 3x + 2, and a range of x values to see its graph drawn on axes with a grid. A table of values for the same range appears below the graph.

Angles in trig functions are in radians here, as is usual for graphs. Points where the function is not defined are left as gaps in the curve and marked in the table.

What you can plot

The plotter understands x, numbers, brackets, the operators + - * / ^ and %, and the functions sin, cos, tan, asin, acos, atan, ln, log, sqrt, cbrt and abs, plus the constants pi and e. Multiplication can be written out or implied: 2x, 2(x + 1) and 2*x all mean the same thing. Try x^2 - 3x + 2 over -5 to 5 to see a parabola, or sin(x) over -6.28 to 6.28 to see one full wave. The graph samples the function at 240 points across the range and joins them with a smooth curve.

Some functions have gaps. The function 1/x is not defined at x = 0, so the curve breaks there and the table marks that row as not defined. The square root of a negative number is not defined either, so sqrt(x) only draws for x from 0 onwards. The y-axis range is chosen from the values the function actually takes, so the curve always fills the plot area.

Reading the table

The value table lists 11 evenly spaced x values across your range, with f(x) for each. It is the same data the graph is drawn from, so a steep rise on the graph shows up as a fast change in the table. Use it to read exact values at the sampled points instead of estimating them from the picture.

Questions people ask

What functions can I plot?

Any expression in x using numbers, brackets, + - * / ^ and %, the functions sin, cos, tan, asin, acos, atan, ln, log, sqrt, cbrt and abs, and the constants pi and e.

Are trig angles in degrees or radians?

Radians, as is usual for graphs. One full sine wave runs from -6.28 to 6.28, which is -2pi to 2pi.

Why does my graph have a gap?

A gap means the function is not defined there. For example 1/x has no value at x = 0, and sqrt(x) has no value for negative x. The table marks those rows as not defined.

How do I read values from the graph?

The table below the graph lists 11 evenly spaced x values with their f(x) values. Use it for exact readings instead of estimating from the picture.
