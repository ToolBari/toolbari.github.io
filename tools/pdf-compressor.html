Why your PDF is so big

Images are the reason, almost always. Text takes very little space: a whole book of plain text fits in a file smaller than a single photo. Images are the opposite. A PDF that holds photos, scanned pages, screenshots, or charts with pictures can grow to many times the size of a text-only file, because every image is stored inside the file at whatever quality it was saved at.

Scanned PDFs are the worst case. A scanner photographs each page, so a scanned PDF is really a stack of photos, one per page. A ten-page scan can easily be larger than a hundred-page text document. Screenshots are similar: a single full-screen screenshot is far bigger than pages of text. Charts and diagrams made from images add up the same way, especially when they were saved at print quality that no screen ever needs.

There are smaller causes too. A PDF can carry fonts inside it, so it looks the same on every computer, and a file with many embedded fonts is a little bigger than one without. A PDF can also hold hidden layers, such as extra versions of a page, or data left over from the app that made it. These are usually small compared with images, but they explain why two files with the same pages can be different sizes.

The practical point is simple: if your file is big, it is big because of pictures. That is good news, because pictures are exactly what compression shrinks best. Lowering the quality of the images inside a PDF is what makes the file smaller, and that is what every compression tool below does.

How to see what is making your file big

Before you compress, take a minute to look inside the file. Open the PDF and flip through the pages. Are most pages full of photos or scans? Then images are the cause, and compression will help a lot. Are the pages mostly text with one or two small pictures? Then the file should already be small, and if it is not, something else is going on, such as a single huge image hiding on one page.

You can also compare the file with its page count. A text-only document of twenty pages should be well under one megabyte. If a twenty-page file is fifty megabytes, the images inside it are large, and compression has plenty to work with. If a two-hundred-page text file is only a few megabytes, compression will barely help, because there is almost nothing to shrink.

One more check is worth doing: look for pages you do not need. A file that holds a full report when you only need three pages of it is not a compression problem, it is a splitting problem. Three free ways to compress a PDF

Method 1 — a free online tool. The quickest way is a free online compressor that runs in your browser. Open one of the well-known free PDF sites, such as iLovePDF or Smallpdf, and look for the compress tool. Upload your file, pick a quality level, and press compress. The site builds a smaller PDF and gives you a download link. The whole job takes a minute or two, and it works the same way on a phone, a tablet, or a computer. The only thing to remember is that your file travels to the site's server to be compressed, so this method is best for ordinary files, not private ones.

Method 2 — a free desktop app. If your file is private, or if you compress PDFs often, a free desktop app is the better choice, because nothing leaves your computer. PDF24 Tools offers a free desktop app for Windows with a compressor built in, and Sejda offers a free desktop version too. Install the app once, open the compress tool inside it, pick your file and a quality level, and save the result. The first setup takes a few minutes, but after that each compression is quick, and you can work without an internet connection. A desktop app is also the right choice for very large files, because uploading a huge file to a website can be slow.

Method 3 — on your phone. On a phone, the simplest route is the browser method: open a free online compression tool in your phone's browser, upload the file from your phone storage, pick a quality level, and download the smaller file. No app download is needed. Phone browsers handle this well, and the file sizes involved are usually small enough to upload over a normal connection. If the file is very large, wait for a Wi-Fi connection rather than using mobile data, because the upload and the download both count against your data.

Choosing a quality level

Every compression tool offers quality levels, usually named low, medium, and high, or described as maximum, recommended, and least compression. The names are confusing, because they describe different things on different tools: on some, high means high quality and little shrinking, and on others, high means high compression and a much smaller file. Always read the short description next to the level, not just the name.

What the levels really do is change how hard the tool squeezes the images. Light compression lowers image quality a little, so the file shrinks a little and the pages still look almost the same. Medium compression squeezes harder, so the file shrinks a fair amount and photos look slightly softer. High compression squeezes the hardest, so the file shrinks the most, but small text and fine detail may blur.

A simple rule works well. If you only need a small reduction, start with light compression: it keeps the quality high and is usually enough. If you need to halve the file, start with medium. If you need a very large reduction, start with high, but check the result carefully, page by page, before you send it. When compression will not help

Sometimes compression barely helps, and it is better to know why than to keep trying. The most common reason is a file that is mostly scanned images. A scanned PDF is a stack of photos, and photos can only be squeezed so far before they turn unreadable. If your scan is 50 megabytes and you need it under 5, compression alone will not get you there. The honest fixes are to split the file into smaller parts, or to re-scan the pages at a lower quality, which usually helps more than any amount of compressing.

Another reason is a file that is already compressed. A PDF made from photos that were already saved at low quality has nothing left to squeeze, so a second round of compression shrinks it by almost nothing. The same is true of a text-only file: text already takes very little space, so there is nothing to gain.

Common mistakes

Compressing five times in a row. Compressing an already compressed file shrinks it very little and makes the quality worse each time. If the first try did not shrink the file enough, change the quality level or split the file, instead of running the same file through the same tool again and again.

Expecting a 50 megabyte scan to become 1 megabyte. A scanned file is a stack of photos, and photos have a floor: below a certain quality, the words become unreadable. A reduction of half is realistic for many files. A reduction of ninety percent or more is usually not, and the planner will tell you so plainly when your numbers ask for it.

Picking high compression without checking the result. High compression is tempting because it makes the smallest file, but it is also the level most likely to blur small text. Always open the result and read a few pages before you send it, especially the pages with the smallest print.

Uploading private files to a random site. Not every free PDF site is careful with your files. Stick to well-known tools, and for anything private, use a desktop app so the file never leaves your computer. If a site looks rough, asks for payment, or shows you pages of adverts before it lets you work, close it and use a better-known one.

Deleting the original before checking the result. Keep your original file until you have opened the compressed version and checked every page. Storage is cheap, and a lost original is often gone for good. Once the smaller file is checked and saved, then you can tidy up.

Questions people ask

How much can I shrink a PDF by compressing it?

It depends on what is inside the file. A PDF full of large photos can often shrink by half or more, while a text-only PDF may barely shrink at all, because text already takes very little space. The size planner above works out the reduction you need before you start.

Does compressing a PDF make it hard to read?

Light compression is usually hard to notice. Medium compression softens photos a little, and high compression can blur small text and fine detail. Always open the compressed file and check it before you send it.

Can I compress a PDF on my phone?

Yes. Open a free online compression tool in your phone browser, upload the file, pick a quality level, and download the smaller file. No app download is needed for the online method.

Why is my scanned PDF still huge after compressing it?

A scanned PDF is a set of photos of pages, so the whole file is images. Compression can only shrink those images so far. If the file is still too big, split it into parts, or re-scan the pages at a lower quality, which usually helps more.

Is it safe to upload a PDF to a free compressor?

For ordinary files, a well-known online tool is usually fine. For private files such as bank statements or medical records, use a desktop app instead, so the file never leaves your computer.

Should I compress the same PDF more than once?

No. Compressing an already compressed file shrinks it very little and makes the quality worse each time. If the first try did not shrink it enough, change the quality level or split the file instead of compressing it again.
