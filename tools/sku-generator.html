How to use the SKU generator

Type the product name, and the generator makes a code for it straight away. Add a category if you want the code to show which group the product belongs to, and a brand if you stock more than one brand. Pick a code style that suits your shop. Letters and numbers is the usual choice: a short category part, a short name part, and four digits. Numbers only suits shops that already use number codes. Short codes are handy for small labels, and long codes suit shops with many brands and categories. For a whole list of products, use batch mode. Paste the product names, one per line, and the generator makes a code for each one. Before you print a code on a label or write it in your stock list, check it once. Read it out loud, and make sure it is not already in use for another product. A minute of checking now saves an hour of sorting out mixed-up stock later, and it is the one step that turns a good code into a reliable one.

What a good SKU looks like

A good SKU is short, readable and hard to get wrong. Short, because long codes get mistyped and take up room on labels. Readable, because a code that hints at the product is easier to work with than a random string: CLT-CTT-4821 tells you at a glance that the product is a cotton item in the clothing group, while 48219357 tells you nothing at all.

Hard to get wrong is just as important. This generator never uses the letters O or I in the letter parts of a code, because O looks like the number 0 and I looks like the number 1, and a tired eye or a smudged label can mix them up. The letters that remain are clear on a screen, on a printed label and in handwriting, which is what you want when someone is counting stock at the end of a long day.

A good SKU also stays the same. Once a product has a code, keep it, even if the price changes or the product moves to a different shelf. Changing codes breaks your stock records, because the old code is written in your order book and on your labels. If a product is discontinued, retire its code and never give it to a new product, or old records and new stock will get mixed up.

Building a naming system for a whole shop

One code is easy. A whole shop of codes needs a system, and the system is simple: every code has the same shape, and every part of the code means the same thing. The category part says which group the product belongs to. The name part says which product it is. The number part makes the code unique. The variant part, when there is one, says which size or colour it is.

Start by listing your categories and giving each one a three-letter code: CLT for clothing, SHS for shoes, BGS for bags, and so on. Keep the list short and write it down where everyone in the shop can see it. Then make the codes for your products one category at a time, starting with your best sellers. The batch mode on this page can make a whole category of codes in one go.

Keep the system the same as the shop grows. When a new category appears, give it a new three-letter code and add it to the list. When a new product arrives, make its code the same way as the others. A system that everyone follows is worth more than a clever system that only one person understands, so write the rules down in a few lines and keep them near the till.

Sizes and colours without the mess

Sizes and colours are where product codes usually fall apart, because one product becomes many: the same shirt in three colours and four sizes is twelve items, and each one needs its own code. The fix is to keep one base shape for the product and add a short variant part for each size or colour. The red shirt might be CLT-CTT-4821-RED and the blue one CLT-CTT-7392-BLU: same category, same name part, a different number and a different colour part, so each item has a code of its own.

Use the same variant words everywhere. If red is RED on one product, it should be RED on all of them, not RD on one and RED on another. Sizes work the same way: S, M and L for small, medium and large, or the number for numbered sizes. Write your variant list next to your category list, and check a new variant against it before you make the code.

One warning: do not put the size and the colour in the same variant part unless you have to, because the part only holds three letters and two ideas will not fit. If a product needs both, use two variant parts, such as RED-L, or keep the colour in the code and the size in your stock list. The generator adds one variant part, so pick the one that matters most for finding the item on the shelf.

When your shop grows: keeping codes unique

A small shop can keep its codes in its head. A growing shop cannot, and that is when duplicate codes start to appear: two products with the same code, or one product with two codes. Both cause trouble. A duplicate code means the stock count for two products gets mixed into one number, and a product with two codes means nobody knows which one is right.

The batch mode on this page protects against duplicates inside one batch, and the three alternatives give you a spare code if the first one is already in use. Before you print a label, search your stock list for the code to make sure it is new. If you use the inventory tracker on ToolBari, the search box there does the same job for your stock list.

If your shop ever outgrows four digits, switch to the long style, which adds a brand part and gives you more room, or add a digit to the number part. With letters and numbers the combinations run into the millions, so a small shop will not run out of codes. What runs out first is patience with a system nobody wrote down, so keep the category list and the variant list on paper near the till.

Common mistakes

The most common mistake is making codes with no system at all: a random code here, a product name there, and a number that means nothing. It works for ten products and falls apart at a hundred. Pick one shape for every code and stick to it. The second mistake is making codes too long. A code with twenty characters will be mistyped, misread and eventually ignored.

The third mistake is putting the price in the code. Prices change, and a code with a price in it goes stale the first time you change the price. Keep the price in your price list, not in the code. The fourth mistake is reusing a code from a product you stopped selling. Old orders and old stock counts still carry that code, and giving it to a new product mixes the old records with the new ones.

Questions people ask

What is an SKU?

An SKU, short for stock keeping unit, is a code that identifies one product in a shop. Each product gets its own code, so you can find it on the shelf, count it in a stock check and look it up in your records without guessing which item you mean.

How long should an SKU be?

Short enough to read, say and type without mistakes. Eight to twelve characters is a good range for most shops. Longer codes get mistyped and take up room on labels, while very short codes run out of combinations when the shop grows.

Can two products share an SKU?

No. One code belongs to one product, and sharing a code mixes up stock counts, orders and records for both products. Sizes and colours of the same product get their own codes too, with a short variant part that tells them apart.

Should my SKU include the price?

No. Prices change, and a code with a price in it goes stale the first time you change the price. Keep the price in your price list and your stock records, and keep the code to category, product and variant only.

How do I make SKUs for sizes and colours?

Keep one base code for the product and add a short variant part for each size or colour, such as RED for red or L for large. This page adds the variant part for you when you fill in the variant box, and batch mode makes variant codes for a whole list.

What if I run out of codes?

Add a digit to the number part or switch to the long style, which adds a brand part and gives you more room. With letters and numbers the combinations run into the millions, so a small shop will not run out. What matters more is keeping one system and writing it down.
