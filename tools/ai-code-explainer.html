Understand code with AI free in your browser — paste code, pick a level, and get a simple explanation.

How to use

  1. Paste your code into the box.
  2. Pick Beginner or Advanced level.
  3. Tap Explain Code and wait.

Example: Paste "print(2 + 3)" and read what each part does.
