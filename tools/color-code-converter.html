What each colour code means

A colour code is a short piece of text that describes one exact colour, so that a computer, a printer or another person can reproduce it. There are four common ways to write a colour down, and they all describe the same thing from different angles. This page converts between all four, starting from a HEX code.

HEX is the code of the web. It starts with a hash sign and follows it with six digits, in pairs: the first pair is the red, the second pair is the green, and the third pair is the blue. The digits run from 0 to 9 and then from a to f, so ff is the highest value a pair can hold. Pure red is written as #ff0000: full red, no green, no blue. Pure white is #ffffff, all three pairs at full strength, and pure black is #000000, all three at zero. You will see HEX codes in stylesheets, in design tools, and in any place where a web colour is written down.

RGB is the code of the screen. It says the same thing as HEX, but in plain numbers instead of pairs of digits: three numbers from 0 to 255, one for red, one for green, one for blue, written as rgb(255, 0, 0) for pure red. Screens build every colour out of red, green and blue light, so RGB describes a colour in the same terms the screen uses. If you have ever adjusted the red, green and blue sliders in a photo app, you have used RGB without knowing its name.

HSL describes a colour the way a person thinks about it: hue, saturation and lightness. The hue is the colour itself, measured as an angle from 0 to 360 around a colour wheel, so 0 is red, 120 is green and 240 is blue. The saturation is how strong the colour is, from a grey 0 percent to a vivid 100 percent. The lightness is how bright it is, from black at 0 percent through the pure colour at 50 percent to white at 100 percent. HSL is the friendliest way to pick shades: keep the hue, and move the lightness up for a lighter shade or down for a darker one.

CMYK is the code of the printer. It describes a colour as four inks: cyan, magenta, yellow and key, which is black, each as a percentage from 0 to 100. Pure red in CMYK is cmyk(0, 100, 100, 0): no cyan, full magenta, full yellow, no black. Printers mix ink, and ink behaves differently from light, which is why print needs its own system. A colour that looks bright on a screen can look duller on paper, because a screen adds light and paper can only take it away.

Worked example: one colour, four codes

Pure red is the clearest example, because its numbers are simple in every system. Type #ff0000 into the converter and you get four ways of saying the same colour.

HEX: #ff0000. RGB: rgb(255, 0, 0). HSL: hsl(0, 100%, 50%). CMYK: cmyk(0, 100, 100, 0). The HEX code says full red, no green, no blue. The RGB value says the same thing in numbers from 0 to 255. The HSL value says the hue is 0, which is red on the colour wheel, the saturation is 100 percent, which is as vivid as red gets, and the lightness is 50 percent, which is the pure colour, neither darkened nor lightened. The CMYK value says the printer needs no cyan, full magenta, full yellow and no black to make red out of ink.

A second example shows how the numbers move for a colour that is not pure. Take a strong blue, #3366cc. In RGB that is rgb(51, 102, 204): a little red, some green, and a lot of blue. In HSL it is hsl(220, 60%, 50%): the hue sits at 220, between blue and violet on the wheel, the saturation is 60 percent, and the lightness is 50 percent. In CMYK it is cmyk(75, 50, 0, 20): three quarters cyan, half magenta, no yellow, and a fifth black to deepen it. None of these numbers is a guess: each one follows from the HEX code by a fixed rule, and the converter applies that rule the same way every time.

Try a colour of your own now. Pick a colour you like, perhaps the colour of a favourite shirt or a logo, and run it through the converter. Read the HSL value and ask what it tells you: a high saturation means the colour is vivid, a low one means it is muted and close to grey, and a lightness near 50 percent means the colour is at its purest. That reading skill is more useful than any single conversion, because it lets you look at a code and picture the colour before you see it.

Picking colours that work together

Converting a colour is only half the job. The other half is choosing colours that work well together, and the HSL system makes that easier than the others, because it separates the colour from its strength and its brightness.

Start with one main colour, the one people will notice first. Then make a lighter shade and a darker shade of it by keeping the hue and the saturation the same and moving only the lightness up and down. Those three shades always sit well together, because they are the same colour at different brightnesses, and they give you a background, a main colour and a dark colour for text or edges.

If you need a second colour, look across the colour wheel. Colours opposite each other, such as blue and orange, or red and green, stand out against each other, which is useful for a button that must catch the eye. Colours next to each other on the wheel, such as blue and violet, or yellow and green, sit quietly together, which is useful for a calm page. Either pairing works; what matters is choosing on purpose rather than by accident.

Test your colours where they will be used. A combination that looks fine on a bright desktop screen can be hard to read on a phone in sunlight, and a combination that looks fine on paper can look washed out on a screen. The preview on this page is a guide, not a promise, and the real test is always the real screen or the real print.

Common mistakes

The most common mistake is using a CMYK print code on a website. CMYK describes ink, and a screen does not use ink, so a CMYK value pasted into a stylesheet does nothing at all. Use HEX or RGB for screens, and keep CMYK for print files, where the printer expects it.

The second common mistake is picking text and background colours that are too close together to read. Light grey text on a white background, or dark blue text on a black background, might look elegant in a design tool and be unreadable in real life. The rule is simple: text must stand out clearly from what sits behind it. Dark text on a light background, or light text on a dark background, always works. If you are not sure, squint at the screen: if the words vanish, the colours are too close.

The third common mistake is a typo in the code. A HEX code with a missing digit, or a digit typed twice, is a different colour entirely, and sometimes it is not a colour at all. The converter tells you plainly when a code is not valid, so if it reports an error, count the digits: a HEX code needs three or six of them, after the hash sign, and every digit must be from 0 to 9 or from a to f.

The fourth common mistake is trusting one screen. Every screen shows colour a little differently: a phone screen, a laptop screen and a television can show the same code in three slightly different shades. That is normal, and it is why important colours, such as a logo or a brand colour, should be checked on more than one device before they are final.

The fifth common mistake is using too many colours. A page with eight colours looks busy and unfocused, and no single colour gets to stand out. One main colour, one or two shades of it, and one accent colour for the things that matter is enough for almost any page, and it looks calmer and more professional than a rainbow.

What this page cannot do

This page converts colour codes. It does not choose colours for you, and it does not judge whether two colours look good together. Taste is a human job, and a converter can only give you the numbers for the colours you pick.

The converter starts from a HEX code or a colour picker. It does not convert colour names, so typing a word like sky blue will not work: colour names are not exact, and one person's sky blue is another person's pale blue. If you have a colour name, find its HEX code first, or pick the closest colour with the picker and read the code it shows.

The converter also cannot promise that a colour will look the same everywhere. Screens differ, printers differ, and the same code can look slightly different on each. The preview on this page shows the colour as your own device renders it, which is the best guide a web page can give, and the real check is always the real screen or the real print.

Questions people ask

Is this colour converter free?

Yes. You can convert as many colours as you like, free, with no signup and no download.

What is the difference between HEX and RGB?

They describe the same colour in two ways. HEX writes it as six digits after a hash sign, and RGB writes it as three numbers from 0 to 255. The converter shows you both for any colour.

When should I use CMYK?

Use CMYK for print, such as flyers, business cards and posters, because it describes the inks a printer uses. Use HEX or RGB for screens, because a screen builds colour from light, not ink.

Can I convert a colour from RGB back to HEX?

This converter starts from a HEX code. If you only have RGB numbers, pick the matching colour with the colour picker and read the HEX value it shows, or work out the HEX code by turning each RGB number into two HEX digits.

Why does the same colour look different on another screen?

Every screen shows colour a little differently, because screens differ in brightness, settings and age. That is normal. Check important colours on more than one device before you decide they are final.

Does the converter work on my phone?

Yes. Type a code with the keyboard or tap the colour picker to choose a colour, and copy any value with one tap.
