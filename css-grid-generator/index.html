Your CSS






The preview shows the grid container only: the CSS it generates covers the container, not the placement of individual items. Items are numbered in reading order; use grid-column and grid-row in your own stylesheet to place an item in a specific cell.


How to use the CSS Grid Generator


Start by choosing how many columns and rows your grid needs. Columns can be set from 1 to 12 and rows from 1 to 8. Every cell in the preview is numbered, so you can see at a glance how many cells the grid has and where each one sits.


Set the gap to control the space between cells. The gap is measured in pixels and applies between every pair of neighbouring cells, both across rows and down columns. A gap of 0 puts the cells edge to edge.


Choose equal fractions when every column should be the same width. Choose custom widths when columns need different sizes: type the widths separated by commas, for example 1fr, 2fr, 100px. The preview and the CSS update together as you type, so you can see the result of each change straight away. If you type fewer widths than columns, the columns without a width use the browser automatic sizing.


When the grid looks right, press Copy CSS and paste the rule into your stylesheet. Give your container the class grid-container, or change the class name in the copied CSS to match a class you already use.


What the generated CSS means


The output is a single CSS rule for the grid container. display: grid turns the element into a grid container, so its direct children become grid items arranged in rows and columns.


    

  • grid-template-columns sets the width of each column. repeat(3, 1fr) is shorthand for three equal columns, each one fraction of the free space.
    • 

  • grid-template-rows sets the height of each row in the same way. repeat(2, 1fr) makes two rows of equal height.
    • 

  • gap sets the space between rows and columns. One value, such as 16px, applies to both directions at once.
    • 



The fr unit is a share of the free space that is left after fixed-size tracks and gaps are taken out. A column of 2fr gets twice as much free space as a column of 1fr, and a column of 100px always stays 100 pixels wide. Mixing fr units with pixel widths is a normal way to build layouts with a fixed sidebar and a flexible main area.


Questions people ask


What does 1fr mean in CSS grid?
One fr is one share of the free space left in the grid container after fixed-size tracks and gaps are taken out. Columns written as repeat(3, 1fr) share the available width equally, so each column gets one third of the space.


Can I mix fixed and flexible column widths?
Yes. Choose custom widths and type widths separated by commas, for example 1fr, 2fr, 100px. The last column stays 100 pixels wide and the remaining space is shared between the two flexible columns, with the second getting twice the share of the first.


What is the gap property?
The gap property sets the space between grid rows and columns in one place. A gap of 16px puts 16 pixels between every pair of neighbouring cells, without adding space around the outside of the grid.


Does the generated CSS work in all browsers?
CSS grid is supported by all modern browsers, including current versions of Chrome, Firefox, Safari and Edge. Very old browsers do not support it, so check your own browser support needs before using grid on a public site.
