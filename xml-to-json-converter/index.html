This converter handles common XML structure. Very large files may be slow, and it does not validate against a schema or DTD.


How the conversion works


Each XML element becomes a JSON value. An element that holds only text becomes a plain string, and an element with child elements becomes an object whose properties are the child tag names. When several children share the same tag name, they are grouped into a JSON array in document order, so a list of repeated items stays a list.
Attributes are kept under a special @attributes object on the element, so no information is lost. If an element has both text and child elements, the text is kept under #text. Empty elements become an empty string, and CDATA sections are read as plain text.
  • One root element is required, as in any well-formed XML document.
  • Comments and processing instructions are skipped.
  • Entity references such as &amp; and &lt; are decoded to their characters.


Tips for clean XML


XML must be well-formed to convert: every opening tag needs a matching closing tag, attribute values must be quoted, and there must be exactly one root element. If the converter reports an error, it names the problem and the position, so you can fix that spot and try again.
Watch out for stray ampersands and angle brackets inside text. In XML, an ampersand must be written as an entity, and a less-than sign must be escaped, otherwise the document is not valid XML and no converter can read it.


Questions people ask


What happens to XML attributes?
Attributes are collected under an @attributes object on the element, so an element with an id attribute becomes an object with an @attributes property holding the id.


What happens when an element repeats?
Repeated child elements with the same tag name become a JSON array, in document order. A single child stays a plain value or object.


Does the converter keep the order of elements?
Yes. Child elements appear in the JSON in the same order as in the XML, grouped by tag name where they repeat.


What if my XML is invalid?
The converter shows a plain error message naming the problem, such as a mismatched closing tag or an unclosed element, and no JSON is produced.
