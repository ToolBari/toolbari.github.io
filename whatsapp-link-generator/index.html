How the link works

The link uses the wa.me address format: the phone number, with its country code and no plus sign, spaces or leading zeros, followed by the message as a text parameter. Opening the link starts a chat with that number in WhatsApp, with your message already typed in the message box.

Enter the number exactly as it would be dialled internationally. A missing country code sends the chat to the wrong number or fails to open, so double-check the first digits before sharing.

Using the QR code

The QR code holds the same link, so anyone who scans it lands in the same chat with the same prefilled message. It suits printed material such as business cards, menus, receipts and shop windows, where typing a link would be awkward.

Download the QR code as a PNG image and print it at a size people can scan comfortably from where they stand. Test the printed code with your own phone before printing a large batch.

Sharing the link safely

A click-to-chat link invites anyone who sees it to message you, so share it where you are happy to be contacted. It works well on a business card, a shop sign or a website contact page, and less well in places where you do not want strangers writing to you.

The prefilled message is only a suggestion: the other person can edit or delete it before sending. Keep it short and clear, so they know what to write even if they change the wording.

Questions people ask

What format does the number need?

Use the full international number: country code followed by the number, digits only, with no plus sign, spaces or brackets. For example, a UK mobile starting with 07700 becomes 447700900123.

Is the message sent automatically?

No. The link opens WhatsApp with your message prefilled in the chat box, and the person opening the link still has to press send.

Do I need a WhatsApp account to make a link?

No. Anyone can create a link for any number. Only the person opening the link needs WhatsApp installed to start the chat.

Can I use the QR code in print?

Yes. Download the QR code as a PNG image and print it on cards, menus or signs. Test the printed code with your own phone before printing many copies.
