Convert and resize in one pass

  1. Choose the image — a phone photo, screenshot or downloaded picture.
  2. Pick JPG for the smallest general-purpose photo, PNG for lossless graphics and transparency, or WebP for a modern web file.
  3. Add a width, a height, both or neither, using the exact resize rules below.
  4. Convert and download the new file. Your original stays untouched.

Exact resize behaviour — no surprises

  • No width, no height: the original pixel size is kept.
  • Width only: height scales in proportion — for a 1600×1200 image, width 800 gives 800×600.
  • Height only: width stays at the original width — the same 1600×1200 image at height 300 becomes 1600×300, so it may look stretched.
  • Width and height: exactly those dimensions are used, even if the ratio changes.

Which output should you choose?

  • JPG — photos and forms; transparent pixels are placed on white.
  • PNG — logos, screenshots and graphics that need transparency or lossless pixels.
  • WebP — websites and sharing where a smaller modern format is accepted.

Questions people ask

Can I convert JPG to PNG?

Yes. Choose a JPG, select PNG and convert. The picture gains a PNG file format, but a JPG has no transparent areas, so no new transparency is created.

What happens when a transparent PNG is converted to JPG?

The full ToolBari converter paints a white background behind the image before encoding it as JPG, because JPG does not support transparency.

Which formats does the Image Converter support?

It opens image files your browser can read and writes exactly three output formats: JPG, PNG and WebP. JPG and WebP are encoded at 0.92 quality in the ToolBari tool; PNG is lossless.

Does resizing by height alone keep the original ratio?

Not in the ToolBari converter. Enter a width alone and the height scales in proportion. Enter a height alone and the width stays at the original width, so the picture can stretch or squash; enter both values to set the exact output size.
