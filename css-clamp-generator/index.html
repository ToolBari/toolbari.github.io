How clamp works

The clamp function takes three values: a minimum, a preferred value, and a maximum. The browser uses the preferred value, but never lets the result go below the minimum or above the maximum. The preferred value is usually a mix of viewport units and pixels, so it grows as the screen widens.

That mix is what this tool calculates. The slope says how fast the size grows per viewport width, and the intercept shifts the line so it passes exactly through your minimum size at your smallest viewport and your maximum size at your largest one.

Choosing your sizes

Start with the two ends. The minimum is the smallest size that still reads comfortably on a phone, and the maximum is the largest size that still looks right on a wide screen. The viewport range should cover the screens your visitors actually use — 320 to 1200 pixels is a common choice.

Test the result with the preview slider: drag it from narrow to wide and watch the text grow smoothly, with no jumps. If the text grows too fast, narrow the size range; if it barely changes, widen it.

Clamp and responsive design

Before clamp, fluid type needed several breakpoints: one size for phones, another for tablets, another for desktops, with a jump at each step. Clamp replaces those steps with one smooth line, so the text grows steadily at every width in between.

That smoothness is the point. Readers on an in-between screen size get a size that fits their screen, not the nearest breakpoint's guess.

Questions people ask

What does clamp do?

It lets one CSS value grow smoothly between a minimum and a maximum as the viewport widens.

What units can I use?

This tool uses pixels, which is the most common choice for fluid type and spacing.

Does clamp work in all browsers?

All modern browsers support clamp. Older browsers ignore the declaration, so test if you support them.

Can I use clamp for things other than text?

Yes. It works for any size value, such as padding, margins, gaps and widths.
