League Table Maker

Paste your match results, one per line, and this tool builds a sorted league table with played, won, drawn, lost, goals for, goals against and points. Teams are ranked by points, then goal difference, then goals scored, then name.

The table follows the tiebreak order shown on this page. Real leagues sometimes use different tiebreakers, such as head-to-head results, so check your league rules before publishing a table.

How to enter results

Write one result per line in the form Team A 2-1 Team B. The first team is the home team and the first number is its score. Team names can have more than one word, and extra spaces around the score do not matter.

Lines that do not match the format are skipped, and their line numbers are shown under the table so you can fix them and rebuild. Every correctly written result still counts, even if another line has a mistake.

How the table is sorted

A win is worth 3 points and a draw is worth 1 point. Teams are ranked by points first, then by goal difference, then by goals scored, and finally by team name in alphabetical order.

The columns are: P for matches played, W for won, D for drawn, L for lost, GF for goals for, GA for goals against, GD for goal difference and Pts for points. Goal difference is goals for minus goals against.

Keeping a season table up to date

The tool has no memory, so paste the full list of results each time you rebuild the table. Keep your results in a text file or a note, add each new matchday to the list, and paste the whole list again to get the current standings.

Because every result is counted from scratch, fixing an old score is easy: correct the line in your list and rebuild. The table always reflects exactly the results you paste, nothing more.

Questions people ask

What format do results need?

One result per line, written as Team A 2-1 Team B. The first team is the home team and the first number is its score. Team names can have more than one word.

What happens to a line with a mistake?

The line is skipped and its line number is shown under the table, so you can fix it and rebuild. All correctly written results still count.

How are tied teams separated?

By goal difference first, then goals scored, then team name in alphabetical order. This order is shown next to the table.

Can I use this for a knockout tournament?

No. This tool is for leagues where every team plays several matches. For a knockout bracket, use the Tournament Bracket Maker instead.
