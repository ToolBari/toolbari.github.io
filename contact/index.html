You can reach ToolBari about any tool problem, new tool request, or advertising matter. The fastest way to get help is a message to our Facebook Page inbox, and tool problems can also be reported in our Telegram group.

Report a broken tool

If a tool is not working, the most helpful message names the tool and describes what happened. Say which tool you were using, what you were trying to do, and what went wrong instead — for example, whether the page would not load, a button did nothing, or the result looked wrong. Mentioning the tool name first makes it easy to find the problem, and a short description of the steps you took is more useful than a long one.

Before you write, try the tool once more — a page that failed to load the first time sometimes works on a second try. If the problem stays, your message in the Facebook Page inbox or the Telegram group will reach the team either way.

Request a new tool

If you want a tool that is not on ToolBari yet, describe the task it should do rather than only its name. Say what you want the tool to calculate, convert, or create, and what you would use it for. That helps the team understand the idea and decide whether it fits the site.

New tools are added based on demand, so requests from visitors genuinely shape what gets built next. If several people ask for the same kind of tool, that tells the team it is worth making.

Advertising enquiries

For advertising matters, message the Facebook Page inbox and say that your message is about advertising. Mention the tool name if your enquiry relates to a particular tool, and describe briefly what you would like to discuss. We read every message.

What happens after you write

Every message is read. If you reported a broken tool, the team will look at the tool you named; if you asked for a new tool, your idea will be considered along with other requests. There is no need to send the same message twice — one clear message with the tool name and the details is enough.
