HTML to Text Converter

Paste HTML code and this converter strips the tags to leave plain readable text. Paragraphs, headings and line breaks become real line breaks, and the result can be copied or downloaded as a text file.

The converter reads the markup as text and keeps only the words, so tables, images and links lose their structure and addresses. Check the result before reusing it, especially if the original page relied on layout to make sense.

What is kept and what is removed

All tags are removed, and the words they wrapped are kept. Block elements such as paragraphs, headings, list items and table rows become line breaks, so the plain text keeps the shape of the original page instead of running together. Line break tags become line breaks too. Anything inside script and style elements is removed completely, along with the tags themselves, so no code or styling ends up in the result.

Character references are decoded back to plain characters: an ampersand code becomes an ampersand, a non-breaking space becomes a normal space, and numeric codes become the character they stand for. Runs of blank lines are trimmed to a single blank line, and trailing spaces on each line are removed.

Using the plain text

The result appears in the box below the button, with a character and word count above it. Copy it to the clipboard for pasting elsewhere, or download it as a plain text file. The conversion happens entirely in your browser, so the HTML you paste is never sent anywhere.

Link text is kept but the address is dropped, and images leave nothing behind, because plain text has no way to hold them. If you need the addresses from a page, run the same HTML through a link extractor instead. Headings and paragraphs stay in their original order throughout.

Questions people ask

Are line breaks kept in the plain text?

Yes. Paragraphs, headings, list items and line breaks in the HTML become line breaks in the plain text, so the result keeps the shape of the original page instead of running together.

What happens to links and images?

Link text is kept but the address is dropped, and images leave nothing behind, because plain text has no way to hold them. If you need the addresses, use a link extractor on the same HTML instead.

Are scripts and styles removed?

Yes. Anything inside script and style elements is removed completely, along with the tags themselves, so no code or styling ends up in the plain text.

Can I download the result?

Yes. The download button saves the plain text as a .txt file on your device. Nothing is uploaded anywhere; the conversion happens entirely in your browser.
