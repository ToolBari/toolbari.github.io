AES Text Encryptor

Type text and a password to encrypt it with AES-GCM 256-bit encryption, or paste encrypted text to decrypt it with the same password. Everything runs in your browser and nothing is sent anywhere, so losing the password means the text cannot be recovered.

This is a general-purpose text tool, not a certified security product. It uses standard AES-GCM encryption in your browser, but it has not been independently audited, so do not rely on it for highly sensitive information.

How it works

When you press Encrypt, the tool derives a 256-bit key from your password with PBKDF2-HMAC-SHA256, using 600,000 iterations and a fresh random 16-byte salt. Your text is then encrypted with AES-GCM and a fresh random 12-byte IV. The output is one Base64 block holding the salt, the IV and the ciphertext together, so everything needed to decrypt is in that single block.

Because the salt and IV are random every time, encrypting the same text with the same password gives a different result on every run. That is normal: every one of those outputs decrypts back to the same text with the same password. To decrypt, paste the whole Base64 block and enter the same password.

What to remember

Everything runs in your browser and nothing is sent anywhere, so there is no copy of your password or your text on any server. That also means a forgotten password cannot be reset: if you lose the password, the encrypted text cannot be recovered.

Always copy the whole encrypted block, from the first character to the last. If even one character is missing or changed, decryption fails with a plain message and no partial output. This tool encrypts text you type or paste — it does not encrypt files.

Questions people ask

What encryption does this tool use?

It uses AES-GCM with a 256-bit key, through the Web Crypto API built into your browser. The key is derived from your password with PBKDF2-HMAC-SHA256 and 600,000 iterations, using a random 16-byte salt and a random 12-byte IV for every encryption.

Why is the encrypted text different every time?

The salt and IV are random for every encryption, so the same text and password produce a different output on every run. That is expected: any of those outputs decrypts back to the same text with the same password.

What happens if I forget the password?

The text cannot be recovered. There is no reset and no copy stored anywhere, because everything runs in your browser and nothing is sent to a server. Keep your password somewhere safe.

What does 'wrong password or damaged data' mean?

It means the password does not match the one used to encrypt the text, or the encrypted text was changed or pasted incompletely. Check the password and make sure you pasted the whole Base64 block, then try again.
