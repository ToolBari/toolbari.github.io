How to use the CSS animation generator

  1. Pick an effect from the list — fade in, slide in, scale up, rotate or bounce.
  2. Set the duration in seconds, the timing function, the delay before it starts, and how many times it repeats.
  3. Watch the preview box run the animation. Press Replay animation to run it again.
  4. Copy the CSS below the preview and paste it into your stylesheet. Change .element to the class name of the element you want to animate.

The six animation effects

Fade in starts the element invisible and brings it to full opacity. Slide in from left and slide in from top move the element into place from outside its starting position while fading it in. Scale up grows the element from half its size to full size. Rotate turns the element one full circle. Bounce drops the element and lets it rebound twice, like a ball settling on the ground.

What the generated CSS does

The output has two parts. The @keyframes block names the animation and describes what changes between its start and end states. The animation line attaches that animation to an element: it gives the name, the duration, the timing function, the delay and the iteration count in one shorthand. The timing function controls the pace — ease starts slow, speeds up and slows down again, while linear moves at a steady speed. The delay waits before the first run, and the iteration count sets how many times the animation repeats.

Questions people ask

What is a CSS animation?

A CSS animation changes how an element looks over time. You describe the start and end states in a @keyframes block, then attach it to an element with the animation property, which sets the name, duration, timing, delay and number of repeats.

Do I need JavaScript to use the CSS from this tool?

No. The output is plain CSS. Paste the @keyframes block and the animation line into your stylesheet, change .element to your own class name, and the animation runs on its own.

Why does my animation play only once?

The iteration count controls how many times it repeats. Choose 1 for a single run, a higher number for a set number of repeats, or infinite to keep it running until the page changes.

Will this animation work in every browser?

CSS animations work in all modern browsers. The output uses the standard syntax with no prefixes, so it runs in current versions of the browsers people use today.
