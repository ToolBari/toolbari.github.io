Staying safe with passwords

  • Use a different password for every important account — one leak should never open everything.
  • Length beats cleverness: a long random password is far stronger than a short complicated one.
  • If you write a password down anywhere, keep it in a secret place — the same advice the tool itself gives.

Questions people ask

How long should a password be?

At least 16 characters for important accounts like email and banking. The generator starts at 16 for exactly this reason.

Are the generated passwords stored anywhere?

No. Passwords are generated in your own browser when you press the button — they are not sent to or kept on a server.

Should I use the same strong password everywhere?

No. A strong password reused on ten sites is only as safe as the weakest of those sites. Generate a fresh one for each account.
