Scientific Calculator

Type an expression or tap the buttons to evaluate it with trig functions, logarithms, powers, roots and the constants pi and e. Each result is added to a history list below the calculator.

History

This calculator evaluates what you type with a small built-in parser, in your browser only. Angles use the mode you select above, so check the mode before trusting a trig result.

What you can type

The calculator understands the usual arithmetic operators (+, -, *, / and ^ for powers), brackets, and the percent sign % for a remainder. It also supports sin, cos and tan, their inverses asin, acos and atan, natural log ln, base-10 log, square root sqrt, cube root cbrt and absolute value abs. The constants pi and e are built in, and you can write 2pi or 2(3 + 4) and the multiplication is understood. Try sin(30) + sqrt(16) * 2 in degrees mode: sin(30) is 0.5 and sqrt(16) is 4, so the result is 8.5.

Angles matter. In degrees mode, sin(30) means the sine of 30 degrees, which is 0.5. In radians mode the same input means the sine of 30 radians, which is about -0.988. Use the angle mode menu to match the problem you are solving. Inverse trig functions return degrees in degrees mode and radians in radians mode.

Order of operations

Expressions follow the usual order: brackets first, then powers, then multiplication and division, then addition and subtraction. So 2 + 3 * 4 is 14, not 20, and 2^3^2 is 512 because powers group from the right. If an expression cannot be read, for example because a bracket is missing, the calculator says so instead of guessing. Division by zero is not defined, so it is reported as an error rather than a number.

Questions people ask

How do I use the trig functions?

Type or tap a function with brackets, such as sin(30) or cos(45). Check the angle mode first: in degrees mode the number inside is degrees, and in radians mode it is radians.

What is the difference between ln and log?

ln is the natural logarithm, base e, while log is the base-10 logarithm. Both need a positive input: ln(e) is 1 and log(100) is 2.

Can I use pi and e in expressions?

Yes. Type pi for 3.14159 and e for 2.71828, or tap the pi and e buttons. You can write them next to numbers, so 2pi means 2 times pi.

Why does the calculator show an error for my expression?

The most common causes are a missing closing bracket, a function name typed without brackets, or division by zero. Check the expression and try again; nothing is calculated until the expression reads correctly.
