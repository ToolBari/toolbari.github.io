Decimal and binary units

There are two ways to count file sizes. Decimal units step by 1000: one kilobyte is 1000 bytes, one megabyte is 1,000,000 bytes, one gigabyte is 1,000,000,000 bytes and one terabyte is 1,000,000,000,000 bytes. Binary units step by 1024: one kibibyte is 1024 bytes, one mebibyte is 1,048,576 bytes, one gibibyte is 1,073,741,824 bytes and one tebibyte is 1,099,511,627,776 bytes.

Storage makers usually quote decimal units, while operating systems often show binary units, which is why a drive can look smaller once it is plugged in. The gap grows with size: a decimal gigabyte is about 7 percent smaller than a binary gibibyte. This converter shows both side by side so the difference is plain to see.

Bits and bytes

One byte holds 8 bits. To convert bytes to bits, multiply by 8; to convert bits to bytes, divide by 8. Network speeds are often quoted in bits, while file sizes are quoted in bytes, so a file of 8 megabytes holds 64 megabits. Mixing the two up is the most common cause of wrong download-time guesses.

The table shows the bit count for every size you enter, alongside the byte count. Very small results are shown in scientific notation, and very large numbers are rounded to four decimal places for display, with the full byte count always shown so you can see the exact figure.

Questions people ask

Why is a kilobyte sometimes 1000 bytes and sometimes 1024?

Both conventions exist. Decimal kilobytes use 1000 bytes and are common for storage packaging, while binary kibibytes use 1024 bytes and are common inside operating systems. This converter shows both so you can see each answer.

What is the difference between MB and MiB?

MB is the decimal megabyte, which is 1,000,000 bytes. MiB is the binary mebibyte, which is 1,048,576 bytes. The gap grows with size: a decimal gigabyte is about 7 percent smaller than a binary gibibyte.

How many bits are in a byte?

One byte holds 8 bits. To convert bytes to bits, multiply by 8; to convert bits to bytes, divide by 8. This converter shows the bit count for every size you enter.

Can I convert very large sizes?

Yes, up to terabytes and tebibytes. Very large numbers are rounded for display, and the full byte count is always shown so you can see the exact figure.
