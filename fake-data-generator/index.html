Generate clearly-fake test records for your software: made-up names, email addresses on example domains, invented street addresses, company names and phone-style numbers. Choose how many records you need and what each record holds, then copy the results or download them as a CSV file.

Your records

Press "Generate records" to create your test data.

This data is for software testing only. It must not be used to impersonate anyone, to create accounts under a false identity, or to contact real people. The records are invented, and any resemblance to a real person is a coincidence.

How to use the Fake Data Generator

Set how many records you need, from 1 to 50. Then pick what each record holds: a name and an email address, a name with an email address and a phone-style number, or a full record with a name, an email address, a street address, a company name and a phone-style number. Press Generate records and the records appear below the buttons.

Press Copy to copy the records as plain text, one record per line, so you can paste them into a document or a test script. Press Download CSV to save the same records as a CSV file with a header row naming the columns, which opens directly in a spreadsheet or imports into a test database.

Every run picks fresh values at random from the built-in lists, so generating again gives a different set of records. If you want to keep a set, copy it or download the CSV before you generate the next batch.

What makes the data clearly fake

Nothing this tool generates could be mistaken for a real person's details. Every part of a record is built from invented pieces, and the pieces are chosen so that the result is plainly test data.

  • Names come from a built-in list of clearly invented names, such as Zara Quill or Finn Wobble. No real names are used.
  • Each email address is built from the made-up name followed by an @example.com ending, a domain reserved for examples that cannot receive mail.
  • Street addresses use invented street names, such as Wobble Lane or Fable Street, with a placeholder town name such as Sampletown.
  • Company names are invented, such as Testwick Labs or Wobble Widgets, and phone-style numbers use the 555 pattern set aside for fictional use.

Because the data is obviously fake, it is safe to paste into screenshots, demos and test databases without risking anyone's real details. It is still test data, though: never use it where a real identity is required, and never present it as belonging to a real person.

Questions people ask

Is the generated data real?

No. Every name comes from a built-in list of invented names, every email address ends with an example domain reserved for examples, street names and the town name are invented, and phone-style numbers use the 555 pattern that is set aside for fictional use. No record belongs to a real person.

Can I use this data in a real signup form?

No. The data is for software testing only, for example filling a test database or checking how a form handles a list of records. Do not use it to create accounts or to pretend to be someone else.

What does the CSV download contain?

The download is a plain CSV file with one record per line and a header row naming the columns, so it opens directly in a spreadsheet or imports into a test database. The columns match the record type you chose.

Can I generate the same records twice?

Each run picks names, streets and companies at random from the built-in lists, so a second run gives a different set of records. If you need the same set again, download the CSV file before generating a new batch.
