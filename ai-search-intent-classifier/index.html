AI Search Intent Classifier

This tool sorts keywords into four search-intent classes — Informational, Commercial, Transactional and Navigational — using a signal-word list shown on this page. Keywords that match no signal word go into an unsure bucket, and you get counts for every class.

Classification is heuristic — it matches signal words, not real search behaviour.

Classification is heuristic. It matches signal words, not real search behaviour, so a keyword can land in the wrong class — treat the result as a starting point. This tool works fully in your browser and calls no AI service, API, or backend.

How to use the classifier

Paste your keywords into the box, one per line, and press "Classify keywords". The tool shows the keywords in each class with a count, plus an unsure bucket for keywords that matched no signal word. Duplicate lines are counted once, and you can copy the whole result with the copy button.

Read the unsure bucket first. Those keywords need a human decision: look at what the searcher is probably trying to do and place them by hand. A keyword with no signal word is often the most interesting one in the list.

The signal-word list

The tool matches whole signal words inside each keyword. The lists are: Transactional — buy, order, purchase, price, pricing, cost, cheap, discount, deal, coupon, sale, checkout, subscribe, quote, hire. Commercial — best, top, review, vs, versus, compare, comparison, alternative, recommend, recommended, rating. Navigational — login, sign in, website, official, homepage, app, contact, support, account. Informational — how, what, why, when, where, who, guide, tutorial, tips, learn, explained, meaning, definition, examples, ideas, ways.

If a keyword matches more than one list, the first match in this order wins: Transactional, then Commercial, then Navigational, then Informational. So "best buy laptops" is classed Transactional because "buy" outranks "best". A keyword that matches no list at all goes into the unsure bucket.

What each intent class means

Informational searchers want to learn something: they ask questions and read guides. Commercial searchers are comparing options before they decide: they read reviews and weigh alternatives. Transactional searchers are ready to act: they want to buy, order, book or sign up. Navigational searchers want a specific site or page: they type a name and expect to land on it.

The class shapes the page you should build. An informational keyword needs a clear answer, a commercial keyword needs an honest comparison, a transactional keyword needs a simple next step, and a navigational keyword needs the right page to land on. Getting the class wrong usually means building the wrong page.

When you are unsure about a keyword, search for it yourself and look at the pages that rank. If the top results are guides, the intent is informational; if they are product pages, it is transactional; if they are comparisons, it is commercial. The results page is the most honest signal of all — use it to check the keywords that matter most.

Questions people ask

What is search intent?

Search intent is what the searcher wants to do: learn something, compare options, buy something, or reach a specific site. The same words can carry different intent, which is why the class matters when you plan a page.

What happens when a keyword matches two lists?

The first match in the priority order wins: Transactional, then Commercial, then Navigational, then Informational. The full signal-word list and the priority order are shown on this page.

What goes in the unsure bucket?

Keywords that match no signal word in any list. They need a human decision — read the keyword, think about what the searcher wants, and place it by hand.

Is the classification exact?

No. It is a heuristic that matches signal words, not real search behaviour. It is a fast first sort for a long list, not a final answer for any single keyword.
