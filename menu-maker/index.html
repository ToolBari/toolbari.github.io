Menu Maker

Add your dishes with prices and sections to build a neat printable menu for a restaurant or cafe. The menu is made in your browser, so nothing is uploaded.

The dishes and prices on the menu are exactly what you type. This maker does not suggest dishes or prices.

Organising by section

Give each dish a section, such as starters, mains, desserts or drinks, and the menu groups the dishes under section headings. Sections appear in the order you first use them, so the first section you type comes first on the menu.

Dishes without a section are grouped under a plain Menu heading, so nothing is left out. Keep section names short and consistent, since two spellings of the same word will make two separate groups.

Writing dish lines

Each dish has a name, an optional short description, and a price. The description is a good place for the main ingredients or a note like spicy or vegetarian, kept to a few words so the menu stays easy to scan.

All dishes and prices on the menu are exactly what you type. This maker never suggests dishes or prices, and it does not convert between currencies.

Printing tips

Print the menu on a single page if it fits, so customers can see everything at once. A clear heading with the restaurant name at the top makes the menu look tidy, and grouping dishes by section helps customers find what they want quickly.

Put the menu where customers can read it before they order, such as on the table or near the door. When dishes or prices change, print a fresh copy and take the old one down, so nobody orders from an out-of-date menu.

Questions people ask

How are sections shown?

Dishes are grouped under their section headings, and sections appear in the order you first use them on the menu.

Can I add more dishes?

Yes. Use the Add dish button for more rows, and Remove on any row to take it out.

What if a dish has no description?

The description is optional. Dishes without one simply show the name and the price.

How do I print or keep the menu?

Use the Print button to open the print dialog with just the menu, or download the menu as a file to keep or send.
