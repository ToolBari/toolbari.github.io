Factor Calculator

Enter a whole number to see all of its factors, its prime factorization and how many factors it has. The division steps that produce the prime factorization are shown too.

This calculator accepts whole numbers from 1 to 1,000,000,000,000. Very large numbers near the top of that range can take a moment, because every possible factor up to the square root is tested.

What factors are

A factor of a number is a whole number that divides it exactly, with no remainder. The factors of 12 are 1, 2, 3, 4, 6 and 12. Factors come in pairs: if 3 is a factor of 12, so is 4, because 3 times 4 is 12. That is why the calculator only needs to test numbers up to the square root. Every factor above the square root pairs with one below it. A perfect square has an odd number of factors, because its square root pairs with itself.

Prime factorization breaks a number into primes: 360 = 2 x 2 x 2 x 3 x 3 x 5, usually written as 2^3 x 3^2 x 5. The exponents in the prime factorization also tell you how many factors there are. Add 1 to each exponent and multiply: for 360, (3 + 1) x (2 + 1) x (1 + 1) = 24 factors. The calculator lists all of them and shows the division chain that finds the primes.

Special cases

The number 1 has exactly one factor, itself, and no prime factorization, because 1 is neither prime nor composite. A prime number has exactly two factors, 1 and itself. If you enter a prime, the calculator says so. The number 0 is not accepted here, because every whole number divides 0 and it has no finite factor list.

Questions people ask

What is a factor?

A factor of a number is a whole number that divides it exactly with no remainder. The factors of 12 are 1, 2, 3, 4, 6 and 12.

What is prime factorization?

Prime factorization writes a number as a product of prime numbers. For 360 it is 2 x 2 x 2 x 3 x 3 x 5, written as 2^3 x 3^2 x 5.

How do you count the factors of a number?

Take the prime factorization, add 1 to each exponent and multiply the results. For 360 = 2^3 x 3^2 x 5 the count is (3 + 1) x (2 + 1) x (1 + 1) = 24.

Does 1 have a prime factorization?

No. The number 1 has only one factor, itself, and it is neither prime nor composite, so it has no prime factorization.
