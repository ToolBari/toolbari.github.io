What a PDF is, in plain words

A PDF is a file that keeps a document looking the same on every screen and every printer. The letters stand for Portable Document Format, and the idea behind it is simple: the person who made the file wanted it to look identical wherever it is opened. A letter, a school form, a bank statement or a textbook chapter saved as a PDF will show the same layout, the same fonts and the same page breaks on a phone, a laptop or a printed page. That is why offices, schools, banks and government departments send documents as PDFs instead of editable files. The format is built for sharing finished work, not for editing it, and that one fact explains most of the trouble people have with PDF files.

There are two very different kinds of PDF, and knowing which one you have saves a lot of time. The first kind holds real text. It was made from a document on a computer, so the words inside it are actual characters that you can select, copy and search. If you open the file and drag your finger or mouse over a sentence, the words highlight, and you can copy them into another app. The second kind is a scanned PDF. It was made by a scanner or a phone camera, so each page is really a picture of a page. The words look the same on screen, but to the computer they are just dots of ink in an image. You cannot select them, you cannot search them, and a converter cannot turn them into editable text until a program reads the pictures first. That reading step is called OCR, short for optical character recognition, and it is the key to working with scanned files.

Most PDF jobs fall into a small set of tasks, and this hub is organised around them. You might want to change the words, which means converting the PDF into a Word document. You might want to join several files into one, or pull a few pages out of a long file. You might have a file that is too big to email, or a form that needs filling in, or a signature that needs adding. You might simply want the text out of the file so you can reuse it. Each card on this page leads to a tool or a guide for one of those jobs, and each guide explains the honest way to do it, including what the free tools can and cannot do.

If you are not sure which kind of PDF you have, try the simplest test first. Open the file and try to select a sentence with your finger or mouse. If the words highlight and copy, you have a real-text PDF, and conversion and editing will be straightforward. If nothing selects, or if the whole page selects as one big picture, you have a scan, and your first step is OCR. Skipping that check is the most common reason a conversion returns an empty or useless file, and it is also the easiest mistake to avoid.

Free tools and paid apps

PDF software comes in two kinds: free tools that do one job well, and paid apps that do everything in one place. For most people, the free tools are enough. Converting a file now and then, merging two documents, shrinking a file to email it, or signing a form are all jobs that free tools handle without trouble, and the guides on this page name the free options and show the steps. Paid apps make sense when PDF work is part of your daily job, when you need to edit complex documents every day, or when you need features like batch processing and advanced security. The honest rule is to start free, and only consider paying when a free tool has actually failed you more than once, because many people pay for features they never use.

Before you start: three quick checks

Three quick checks, done before you open any tool, will save you from the most common PDF frustrations. First, check whether your PDF is text or a scan, using the selection test described above. If it is a scan, your first job is OCR, not conversion, and starting with the OCR guide will save you a failed attempt. Second, check the size of the file and the limit you are working to. If an email or a form asks for a file under a certain size, note the number before you start, so you know how much shrinking you need instead of guessing. The size planner on the compressor page turns those two numbers into a clear target. Third, make a copy of the original file before you edit, split or convert it. Keep the untouched original somewhere safe, and work on the copy. If a step goes wrong, you can start again from the original instead of losing the only version you had.

It also helps to know what the finished file is for. A document you will print wants different settings from one you will read on a phone. A file you will email needs to be small, while a file you will archive can stay large and sharp. A form you will send to an office needs to look clean and complete, with no half-filled fields. Knowing the destination before you start tells you which method to pick and how much care the job needs, and it stops you from redoing work that was already good enough.

Common mistakes with PDF files

The most common mistake is uploading a scanned PDF to a converter and expecting editable text back. The converter can only work with the text that is in the file, and a scan has no text in it, only pictures of words. The result is either an empty document or a document full of errors, and the fix is to run OCR first. The second mistake is trusting a free online tool with a private document. Free converters are real services, but your file still travels to their server, and for sensitive papers an offline method is the safer choice. The third mistake is compressing a file again and again, hoping each pass makes it smaller. Compression works once, on the images inside the file, and repeating it only makes the pictures worse while barely changing the size.

Another common mistake is editing the only copy of a file. PDF editors save over the original by default in many cases, so a wrong edit can destroy the only version you have. Always save a copy first, and give the edited file a new name, so the original stays untouched. People also merge files in the wrong order and only notice after sending the result, so check the page order in the merged file before you share it. Finally, many people skip the step of checking the finished file. Open the converted or merged document, scroll through it once, and look at the tables, the images and the last page. A two-minute check catches the broken table or the missing page while there is still time to fix it.

Are these PDF tools free?

Yes. Every tool and guide on this page is free to use in your browser, with no signup and no download. The guides point you to free tools from other makers too, and they say plainly when a tool has a free plan with limits.

Do I need to sign up or install anything?

No. The tools on ToolBari run in your browser, so there is nothing to install and no account to create. Some of the free apps the guides mention need a download, and the guide for each job tells you when that is the case.

Can I convert a PDF to Word on my phone?

Yes. The PDF to Word Converter guide includes a method that works entirely on a phone, using a free online converter in your mobile browser. You open the converter, choose your PDF, and download the Word file it makes.

What is the difference between a scanned PDF and a normal PDF?

A normal PDF holds real text that you can select and copy. A scanned PDF is really a set of photos of pages, so there is no text to copy until a program reads the pictures with OCR. If you cannot select the words in your PDF, it is almost certainly a scan.

Is it safe to upload a private PDF to a free online tool?

For private documents, such as bank papers, medical records or work files, it is safer not to upload them at all. Use an offline method instead, such as a word processor on your own computer, so the file never leaves your device.

Which PDF tool should I start with?

Start from the job, not the tool. If you need to change the words, convert the PDF to Word. If the file is too big to send, compress it. If you need the text out of a scan, start with the OCR and text extractor guide.
