How to set up your intervals

Enter the work length in seconds, the rest length in seconds, and the number of rounds. Work can be from 5 to 600 seconds, rest from 0 to 600 seconds, and rounds from 1 to 20. Setting rest to zero runs work rounds back to back with no break in between. Press Start and the timer begins the first work interval straight away.

The display shows the current phase, the time left in that phase, and which round you are on. Pause stops the countdown exactly where it is, and Start picks it up again from the same second. Reset clears everything back to Ready, so you can change the lengths and start a new session.

Following the timer

A short beep marks each change between work and rest, so you can follow the session without watching the screen. When the last round finishes, a longer tone plays and the display shows Complete. The round counter keeps you honest about how far through the session you are, which helps when the rounds start to feel long. If you lose track, a glance at the phase and the round number tells you exactly where you stand.

The timer runs in this tab, so keep the page open and your device awake while you train. If you switch away to another app, the tab may be paused by the browser on some devices, so the timer is most reliable when it stays on screen. Turn the volume up before you start so the beeps are easy to hear.

How many rounds can I set?

From 1 to 20 rounds.

What do the sounds mean?

A short beep marks each change between work and rest, and a longer tone marks the end of the last round.

Yes. Pause stops the countdown where it is, and Start picks it up again.
