Easing Function Visualizer

Pick an easing curve and a duration to watch a dot travel across the track with that exact timing. The page also draws the curve and shows the CSS timing-function code, ready to copy into your stylesheet.

The preview runs in your browser and the timing may vary slightly on a busy device. The cubic-bezier values shown are the standard CSS equivalents of the named curves.

How to use the visualizer

Choose an easing curve from the list, set a duration between 100 and 10000 milliseconds, and press Play animation. The dot travels across the track with the timing of the chosen curve, and the progress readout shows how far along it is.

The graph under the track draws the curve itself: time runs left to right and progress runs bottom to top. The CSS box shows the timing-function and duration lines, which you can copy with the Copy CSS button.

What easing changes

A linear animation moves at a constant speed from start to finish. An ease-in curve starts slowly and speeds up, an ease-out curve starts fast and slows down, and an ease-in-out curve does both. The same movement can feel snappy, gentle or mechanical depending on the curve.

On the graph, a steep section means fast movement and a flat section means slow movement. A curve that stays low and then rises steeply starts slowly; a curve that rises steeply and then flattens finishes slowly.

Choosing a curve for your animation

Ease-out curves suit things that appear or arrive, because they move quickly at first and settle gently into place. Ease-in curves suit things that leave, because they gather speed as they go. Ease-in-out curves suit movements that both start and end at rest.

Short durations feel snappy and long durations feel slow, so match the duration to the size of the movement. Try the same curve at different durations in the preview to feel the difference.

Questions people ask

What is an easing function?

It controls how an animation speeds up or slows down over its duration. The same movement can feel snappy, gentle or mechanical depending on the curve.

What is cubic-bezier?

It is the CSS way to describe a custom easing curve with four numbers. The code this page shows can be pasted straight into a transition-timing-function or animation-timing-function rule.

Why does ease-in feel slow at the start?

Its curve rises gently at first, so the animated object covers little distance early on and most of its distance near the end.

Can I use the copied code in any stylesheet?

Yes. The timing-function values are plain CSS and work in any modern browser.
