How to use the chatbot script builder

Start by picking a greeting line and a fallback line from the two pickers. The greeting is the first thing a visitor reads, and the fallback is what the chatbot says when it has no matching answer. Then add your question and answer pairs one at a time: type a question visitors actually ask, type the answer you want given, and press Add pair. Each pair appears in the list, where you can remove it if you change your mind.

The preview pane shows the conversation as a visitor would see it: greeting first, then each question and answer in order, then the fallback. When the flow reads well, press Copy script to copy the plain-text script, or Download as text to save it as a file. Hand the script to a developer or paste it into your chatbot platform.

Writing pairs that work

Write questions the way visitors write them, not the way a manual writes them. Short, plain questions match more often than formal ones. Keep answers short too: one or two sentences is enough for most questions, and a long answer in a chat window rarely gets read to the end. If an answer needs detail, point the visitor to a page instead of pasting the whole detail into the chat.

Start with the five to ten questions you hear most often. That small set usually covers most conversations. Add more pairs only when visitors keep asking something new. A script with twenty good pairs beats one with a hundred guessed pairs, because every pair you add is one more answer to keep correct.

Why the fallback line matters

No chatbot answers everything. The fallback line decides what happens when a visitor asks something outside your script, and it shapes how they feel about the whole experience. A good fallback is honest, friendly, and useful: it says the chatbot does not know, and it offers the next step, such as rephrasing the question or reaching a team member.

Never let a fallback pretend to know an answer it does not have. A wrong answer is worse than no answer, because the visitor acts on it. Review your fallback line often, and read the questions it catches: they show you which pairs to add next.

Questions people ask

What does the script contain?

It contains your greeting line, every question and answer pair in order, and your fallback line, arranged as a plain-text conversation script.

How many pairs can I add?

As many as you need. Start with the five to ten questions you hear most often, and add more only when visitors keep asking something new.

Does this tool run a chatbot?

No. It builds the script text only. You paste the script into a chatbot platform or hand it to a developer to set up.

Does the tool save my script?

No. Everything runs in your browser, and nothing you type is sent anywhere or stored. Copy or download the script before you leave the page.
