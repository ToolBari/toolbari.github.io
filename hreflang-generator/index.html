Hreflang Tag Generator

Build the hreflang tags for a page that exists in more than one language or region. Add each version with its language code and URL, then copy the finished block of tags.

Check each URL before you publish. The tags point search engines to the URLs you enter, so a wrong address sends visitors to the wrong page.

How to build your tags

Start with the rows already on the page: one for the English version, one for the United States English version, and one for the fallback page. Type the full URL of each version next to its code, and use Add a row whenever you need another language or region. A row left completely blank is skipped, so you only get tags for the versions you actually fill in.

Press Generate tags and the block of link tags appears in the box below, one tag per version. Each tag names the language and region and points to that version of the page. Copy the block with the Copy tags button, or download it as a text file. If a row has a problem, such as a missing URL or a code in the wrong shape, the message lists the rows to fix and no tags are produced until they are corrected.

Language codes

A language code is two letters, such as en for English or fr for French. You can add a region after a hyphen, such as en-US for United States English or fr-CA for Canadian French. The tool accepts codes in any capitalisation and normalises them for you, so en-us becomes en-US. The special code x-default marks the fallback page shown when no language version matches the visitor.

Every version of a page should carry the full set of tags, including a tag pointing to itself. That way search engines can see the whole group of versions from any one of them. The tags go in the head section of the page, and each version lists the same set.

Questions people ask

What format do language codes use?

A two-letter language code such as en or fr, with an optional region after a hyphen, such as en-US. The code x-default marks the fallback page.

Do I need x-default?

It is optional. It tells search engines which page to show when no language version matches the visitor.

How many versions can I add?

Add as many rows as you need. Each row becomes one link tag in the output.

Where do the tags go?

Paste the tags into the head section of each version of the page, so every version lists all the others.
