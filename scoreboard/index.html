How to use the scoreboard

Type the two team or player names first. The names update on the board as you type, and if you leave a box blank the board falls back to Team A and Team B. Each side has a plus button to add a point and a minus button to take one away, which is handy when a point is given by mistake. Scores never drop below zero, so an extra tap on the minus button does no harm.

The match timer sits below the scores. Set the length in minutes, from 1 to 180, and press Start timer. The countdown shows minutes and seconds, and a message appears when time runs out. Pause stops the countdown where it is, and Start picks it up again. Reset timer clears the countdown, and Reset all clears both the scores and the timer for a new match.

Tips for match day

Open the page on a phone, tablet or laptop where both sides can see it. The score is shown in large text, so it reads well from a few steps away. Set the names and the timer length before the match starts, so the only taps during play are the plus and minus buttons. If the match has halves or periods, pause the timer during the break and start it again when play resumes.

Because the scoreboard does not save anything, note the final score down when the match ends. A quick photo of the screen works well. If you need a fresh board for the next match, Reset all puts both scores back to zero and clears the timer in one tap.

Questions people ask

How do I change the team names?

Type the names in the two name boxes. The scoreboard updates as you type.

Can I take a point away?

Yes. Each team has a minus button that removes one point, and the score never goes below zero.

How long can the timer run?

Set any length from 1 to 180 minutes. The timer counts down and shows a message when time is up.

Does the scoreboard save my match?

No. The score and timer reset when you refresh or close the page, so note the final score down.
